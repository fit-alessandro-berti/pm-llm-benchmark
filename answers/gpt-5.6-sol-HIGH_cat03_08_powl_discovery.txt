The repeated assembly/quality phase can be modeled as:

- `*(IQC, )` — one or more consecutive IQC activities.
- `*(AS, *(IQC, ))` — execute AS once, then optionally repeat a block of one-or-more IQCs followed by another AS.

The testing phase is `*(TST, RT)`, producing `TST (RT TST)*`. Labeling is optional through `X(LB, )`.

### Final POWL structure

Let:

```text
IQC_BLOCK     = *( IQC, _IQC )
ASSEMBLY_LOOP = *( AS, IQC_BLOCK )
TEST_LOOP     = *( TST, RT )
OPTIONAL_LB   = X( LB, _LB )
```

Then:

```text
PO=(
  nodes={
    OR,
    MS,
    QS,
    ASSEMBLY_LOOP,
    TEST_LOOP,
    PK,
    OPTIONAL_LB,
    DP,
    D
  },
  order=transitive_closure({
    OR            --> MS,
    MS            --> QS,
    QS            --> ASSEMBLY_LOOP,
    ASSEMBLY_LOOP --> TEST_LOOP,
    TEST_LOOP     --> PK,
    PK            --> OPTIONAL_LB,
    OPTIONAL_LB   --> DP,
    DP            --> D
  })
)
```

Equivalent PM4Py construction:

```python
from pm4py.objects.powl.obj import (
    StrictPartialOrder,
    OperatorPOWL,
    Transition,
    SilentTransition
)
from pm4py.objects.process_tree.obj import Operator

OR = Transition(label="OR")
MS = Transition(label="MS")
QS = Transition(label="QS")
AS = Transition(label="AS")
IQC = Transition(label="IQC")
TST = Transition(label="TST")
RT = Transition(label="RT")
PK = Transition(label="PK")
LB = Transition(label="LB")
DP = Transition(label="DP")
D = Transition(label="D")

tau_iqc = SilentTransition()
tau_lb = SilentTransition()

# IQC+ = IQC followed by zero or more additional IQCs
iqc_block = OperatorPOWL(
    operator=Operator.LOOP,
    children=[IQC, tau_iqc]
)

# AS (IQC+ AS)*
assembly_loop = OperatorPOWL(
    operator=Operator.LOOP,
    children=[AS, iqc_block]
)

# TST (RT TST)*
test_loop = OperatorPOWL(
    operator=Operator.LOOP,
    children=[TST, RT]
)

# Optional labeling
optional_lb = OperatorPOWL(
    operator=Operator.XOR,
    children=[LB, tau_lb]
)

stages = [
    OR,
    MS,
    QS,
    assembly_loop,
    test_loop,
    PK,
    optional_lb,
    DP,
    D
]

root = StrictPartialOrder(nodes=stages)

# Add the transitive closure of the sequential stage ordering.
for i in range(len(stages)):
    for j in range(i + 1, len(stages)):
        root.order.add_edge(stages[i], stages[j])
```

This model supports:

- `AS` without IQC, as in case 4.
- One or more IQCs between successive assembly executions, including consecutive IQCs as in case 3.
- Any number of `RT, TST` repetitions after the initial test.
- Optional labeling.
- The observed ordering from order receipt through dispatch.
