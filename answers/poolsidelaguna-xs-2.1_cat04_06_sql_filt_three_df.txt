Here's the DuckDB SQL query that implements the requirements:

```sql
SELECT *
FROM event_log
WHERE case_id NOT IN (
    SELECT DISTINCT case_id
    FROM (
        SELECT 
            case_id,
            activity,
            timestamp,
            LEAD(activity, 1) OVER (PARTITION BY case_id ORDER BY timestamp) AS next_activity,
            LEAD(activity, 2) OVER (PARTITION BY case_id ORDER BY timestamp) AS next_next_activity,
            LEAD(timestamp, 1) OVER (PARTITION BY case_id ORDER BY timestamp) AS next_timestamp,
            LEAD(timestamp, 2) OVER (PARTITION BY case_id ORDER BY timestamp) AS next_next_timestamp
        FROM event_log
    ) sub
    WHERE activity = 'Approve Purchase Requisition'
        AND next_activity = 'Create Order'
        AND next_next_activity = 'Confirm Order'
        AND (next_next_timestamp - next_timestamp) > INTERVAL '5 days'
);
```

**Explanation:**

1. **Inner Subquery (`sub`):**
   - Uses window functions to look ahead at the next two events within each case:
     - `next_activity`: Activity of the immediately following event
     - `next_next_activity`: Activity of the event after the next
     - `next_timestamp`: Timestamp of the next event
     - `next_next_timestamp`: Timestamp of the event after the next

2. **Filtering Conditions:**
   - `activity = 'Approve Purchase Requisition'`: Starting point of the sequence
   - `next_activity = 'Create Order'`: Immediate next activity
   - `next_next_activity = 'Confirm Order'`: Activity after the next
   - Time difference between 'Create Order' (`next_timestamp`) and 'Confirm Order' (`next_next_timestamp`) exceeds 5 days

3. **Result Construction:**
   - The outer query excludes all events from cases that meet the above criteria
   - Returns all events from cases that do not have this specific sequence with the timing condition

This query ensures:
- The three activities appear consecutively without any intervening events
- The time constraint is strictly enforced
- Only qualifying cases are excluded while maintaining the complete event history for other cases
