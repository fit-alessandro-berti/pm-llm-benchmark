# Process Mining Visualization Description

This is a **multi-process flow diagram** (process mining/object-centric process model) that shows how five different business object types flow through interconnected process activities, likely from an ERP/procurement-to-pay and order-to-cash system.

## Data Sources (Top Row)
Five object types feed into the process, each with a distinct color and object count:
- **VendorInvoiceItem** (1.2M objects) — teal
- **ReturnOrderItem** (0.8M objects) — red
- **PurchaseRequisitionItem** (2.0M objects) — purple
- **SalesOrderItem** (3.5M objects) — orange
- **PurchaseOrderItem** (5.0M objects) — blue

## Structure
Each object type has its own **Start** node, then flows through shared or dedicated activity nodes:

1. **Procurement path** (purple/blue/red/teal converge):
   - Create Requisition  Approve Requisition  Send Order / Check Stock / Process Return  Approve Payment  Create Invoice  End

2. **Sales/Fulfillment path** (orange/blue):
   - Create Order  Pack Goods  Ship Goods  Confirm Delivery  Close Order  End

## Key Features
- **Colored dots** inside each activity box indicate which object types pass through that step (showing object convergence).
- **Edge labels** show average transition times in milliseconds (e.g., 300ms, 600ms).
- **"Overall" counts** in each activity box represent total object interactions at that step (e.g., "Create Order — Overall: 8.5M").
- Multiple **End** nodes at the bottom represent process completion points for different object lifecycles.

## Purpose
This visualization is typical of **object-centric process mining**, used to analyze how different business documents (requisitions, orders, invoices, returns) interact within shared activities — useful for identifying bottlenecks, shared touchpoints, and cross-object dependencies in an end-to-end procurement and sales process.
