**Recommended DuckDB SQL query:**

```sql
SELECT *
FROM event_log
QUALIFY COUNT(*) OVER (PARTITION BY case_id) <= 6;
```

### Why this works
- `COUNT(*) OVER (PARTITION BY case_id)` computes the total number of events for each case.
- The `QUALIFY` clause (fully supported in DuckDB) filters the result set to keep only those rows whose case has a count ≤ 6.
- `SELECT *` returns every original column for the qualifying events, exactly as requested.
- No extra columns, no subqueries, and no materialization of intermediate tables are required.

### Equivalent standard-SQL alternative (also correct)
```sql
SELECT *
FROM event_log
WHERE case_id IN (
    SELECT case_id
    FROM event_log
    GROUP BY case_id
    HAVING COUNT(*) <= 6
);
```

Both queries produce the same result. The `QUALIFY` version is more concise and idiomatic for DuckDB, which is why the team recommends it as the primary solution. No `ORDER BY` is required by the problem statement.
