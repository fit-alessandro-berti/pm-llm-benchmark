```text
-> (
    'Receive Application (RA)',
    'Validate Form (VF)',
    'Assess Eligibility (AE)',
    * (
        tau,
        -> (
            'Request Missing Info (RMI)',
            'Validate Form (VF)'
        )
    ),
    'Approval Decision (AD)',
    'Send Confirmation (SC)',
    'Archive Case (AC)'
)
```

This represents:

- Initial intake and validation: `RA  VF  AE`
- An optional loop:
  - exit immediately if no information is missing (`tau`), or
  - perform `RMI  VF` one or more times before exiting
- Finalization: `AD  SC  AC`
