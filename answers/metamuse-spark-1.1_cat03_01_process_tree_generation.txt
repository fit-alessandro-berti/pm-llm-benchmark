In `pm4py` the model is:

```
->( A , RG , IA , TI , TC , X(CE,FBP) , LOOP , +(AI,NC) , ->(FAS,DDI) , +(BL,ICP,MRF) )
```

Phase 4 is a loop:

* `A` of the loop must be executed at least once, `B` is the redo.
* To repeat `SC -> X(TM,SPT) -> X(FCE,FBA)` until normal: 

```
BODY = ->( SC , X(TM,SPT) , X(FCE,FBA) )
LOOP = *( BODY , tau )          // BODY tau BODY tau ... BODY
```

If you want to model the `If normal skip loop`:

```
LOOP_OPT = X( tau , *(BODY,tau) )
```

> Strictly `RDT` is `X(FCE,FBA)`.

### Formal notation

**Mandatory loop:**

```
->( A, RG, IA, TI, TC, X(CE, FBP), *( ->( SC, X(TM, SPT), X(FCE, FBA) ), tau ), +(AI, NC), ->(FAS, DDI), +(BL, +(ICP, MRF)) )
```

**With optional entry - exactly the text:**

```
->( A, RG, IA, TI, TC, X(CE, FBP), X( tau, *( ->( SC, X(TM, SPT), X(FCE, FBA) ), tau ) ), +(AI, NC), ->(FAS, DDI), +(BL, +(ICP, MRF)) )
```
`+` is binary so `+(BL,ICP,MRF)` is `+(BL,+(ICP,MRF))`.

### `pm4py` construction - executable

```python
from pm4py.objects.process_tree.obj import ProcessTree, Operator

def leaf(label, parent):
    n = ProcessTree(label=label, parent=parent)
    parent.children.append(n)
    return n

def tau_leaf(parent):
    n = ProcessTree(parent=parent)  # label=None => tau
    parent.children.append(n)
    return n

root = ProcessTree(operator=Operator.SEQUENCE)

# ->(A,RG,IA)
seq_ARI = ProcessTree(operator=Operator.SEQUENCE, parent=root)
root.children.append(seq_ARI)
leaf("A", seq_ARI)
leaf("RG", seq_ARI)
leaf("IA", seq_ARI)

# ->(TI,TC)
seq_TI_TC = ProcessTree(operator=Operator.SEQUENCE, parent=root)
root.children.append(seq_TI_TC)
leaf("TI", seq_TI_TC)
leaf("TC", seq_TI_TC)

# X(CE,FBP)
xor_init = ProcessTree(operator=Operator.XOR, parent=root)
root.children.append(xor_init)
leaf("CE", xor_init)
leaf("FBP", xor_init)

# LOOP part
# X(TM,SPT)
xor_treat = ProcessTree(operator=Operator.XOR)
leaf("TM", xor_treat)
leaf("SPT", xor_treat)

# X(FCE,FBA)  = RDT
xor_redo_test = ProcessTree(operator=Operator.XOR)
leaf("FCE", xor_redo_test)
leaf("FBA", xor_redo_test)

# BODY = ->(SC, X(TM,SPT), X(FCE,FBA))
seq_body = ProcessTree(operator=Operator.SEQUENCE)
sc = leaf("SC", seq_body)
# attach xor children to body
xor_treat.parent = seq_body
seq_body.children.append(xor_treat)
xor_redo_test.parent = seq_body
seq_body.children.append(xor_redo_test)

# *(BODY, tau)
loop_node = ProcessTree(operator=Operator.LOOP)
seq_body.parent = loop_node
loop_node.children.append(seq_body)
tau_leaf(loop_node)

# Optional entry X(tau, LOOP) to model "if abnormal"
xor_opt = ProcessTree(operator=Operator.XOR, parent=root)
root.children.append(xor_opt)
tau_leaf(xor_opt)
loop_node.parent = xor_opt
xor_opt.children.append(loop_node)

# If you want mandatory loop, replace xor_opt with loop_node directly in root

# +(AI,NC)
par_AI_NC = ProcessTree(operator=Operator.PARALLEL, parent=root)
root.children.append(par_AI_NC)
leaf("AI", par_AI_NC)
leaf("NC", par_AI_NC)

# ->(FAS,DDI)
seq_FAS_DDI = ProcessTree(operator=Operator.SEQUENCE, parent=root)
root.children.append(seq_FAS_DDI)
leaf("FAS", seq_FAS_DDI)
leaf("DDI", seq_FAS_DDI)

# +(BL,ICP,MRF) -> binary
par_ICP_MRF = ProcessTree(operator=Operator.PARALLEL)
leaf("ICP", par_ICP_MRF)
leaf("MRF", par_ICP_MRF)

par_BL = ProcessTree(operator=Operator.PARALLEL, parent=root)
root.children.append(par_BL)
leaf("BL", par_BL)
par_ICP_MRF.parent = par_BL
par_BL.children.append(par_ICP_MRF)
```

If the loop must be mandatory, remove `xor_opt` and put:

```python
loop_node.parent = root
root.children.insert(3, loop_node) # instead of xor_opt
```

Then the tree corresponds to:

```
->( ->(A,RG,IA), ->(TI,TC), X(CE,FBP), *(->(SC,X(TM,SPT),X(FCE,FBA)),tau), +(AI,NC), ->(FAS,DDI), +(BL,+(ICP,MRF)) )
```
