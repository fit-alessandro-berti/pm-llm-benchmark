**Deviant cases: 2, 3, and 5.**

**Case 1** follows the full sufficient-inventory path exactly:  
Receive order → Check inventory → Authorize payment → Package items → Ship order → Close order.  
No violations.

**Case 2** violates the required order of activities on the sufficient-inventory path.  
After Check inventory it performs Package items *before* Authorize payment, then proceeds to Ship order and Close order.  
The normative description states that “Authorize payment” must occur after the inventory check and *before* packaging (“payment authorization only makes sense once inventory sufficiency is known” and “Package items should only occur after authorization”). Packaging before authorization is explicitly listed as a deviation.

**Case 3** mixes the two exclusive paths and performs forbidden post-cancellation activities.  
It follows the sufficient-inventory path far enough to Authorize payment, then switches to Cancel order, and still executes Ship order (with no Package items) before Close order.  
The description requires that, once inventory is found insufficient, the process must go directly to Cancel order and then Close order; fulfillment activities are forbidden after cancellation. In particular: “Ship order should only occur after packaging and never after a cancellation.” Shipping after a cancellation (and without packaging) is a clear violation.

**Case 4** follows the insufficient-inventory path exactly:  
Receive order → Check inventory → Cancel order → Close order.  
No violations.

**Case 5** follows the sufficient-inventory path but omits a mandatory step.  
After Authorize payment it proceeds directly to Ship order (then Close order), skipping Package items.  
The description requires that items “should be prepared for shipment” after authorization and that “Only after items have been properly packaged is it appropriate to proceed with Ship order.” Shipping without a preceding Package items activity therefore violates the normative sequence.

These judgments rest on the explicit ordering and mutual-exclusion constraints given in the normative text; residual ambiguities (e.g., whether an extraordinary early cancellation could ever be tolerated) do not alter the clear violations present in cases 2, 3 and 5.
