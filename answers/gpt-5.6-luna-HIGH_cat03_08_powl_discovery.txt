The event log is captured by:

- A mandatory sequence `OR  MS  QS`
- An optional quality-control loop `*(AS, IQC)`, producing:
  - `AS`
  - `AS, IQC, AS`
  - `AS, IQC, AS, IQC, AS`, etc.
- A testing/re-testing loop `*(TST, RT)`, producing:
  - `TST`
  - `TST, RT, TST`
  - `TST, RT, TST, RT, TST`, etc.
- Mandatory packaging
- An optional labeling step
- Mandatory distribution planning and dispatch

```python
from pm4py.objects.powl.obj import (
    StrictPartialOrder,
    OperatorPOWL,
    Transition,
    SilentTransition
)
from pm4py.objects.process_tree.obj import Operator


# Activities
OR = Transition(label="OR")
MS = Transition(label="MS")
QS = Transition(label="QS")

AS = Transition(label="AS")
IQC = Transition(label="IQC")

TST = Transition(label="TST")
RT = Transition(label="RT")

PK = Transition(label="PK")
LB = Transition(label="LB")
DP = Transition(label="DP")
D = Transition(label="D")

tau = SilentTransition()


# Repeated in-line quality control:
# AS, optionally followed by IQC and another AS, repeatedly
assembly_quality_loop = OperatorPOWL(
    operator=Operator.LOOP,
    children=[AS, IQC]
)


# Testing may be followed by re-testing and another test
testing_loop = OperatorPOWL(
    operator=Operator.LOOP,
    children=[TST, RT]
)


# Labeling is optional
labeling_choice = OperatorPOWL(
    operator=Operator.XOR,
    children=[LB, tau]
)


# Overall process structure
root = StrictPartialOrder(
    nodes=[
        OR,
        MS,
        QS,
        assembly_quality_loop,
        testing_loop,
        PK,
        labeling_choice,
        DP,
        D
    ]
)

root.order.add_edge(OR, MS)
root.order.add_edge(MS, QS)
root.order.add_edge(QS, assembly_quality_loop)
root.order.add_edge(assembly_quality_loop, testing_loop)
root.order.add_edge(testing_loop, PK)
root.order.add_edge(PK, labeling_choice)
root.order.add_edge(labeling_choice, DP)
root.order.add_edge(DP, D)
```

In compact POWL notation, the model is:

\[
\text{OR}
\rightarrow
\text{MS}
\rightarrow
\text{QS}
\rightarrow
*(\text{AS},\text{IQC})
\rightarrow
*(\text{TST},\text{RT})
\rightarrow
\text{PK}
\rightarrow
X(\text{LB},\tau)
\rightarrow
\text{DP}
\rightarrow
\text{D}
\]

Here, `tau` represents the option to skip labeling. The two loop nodes allow the repeated patterns observed in the log:

- `*(AS, IQC)` models repeated quality inspection and reassembly.
- `*(TST, RT)` models failed tests followed by re-testing.
