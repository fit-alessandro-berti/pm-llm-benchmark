# Process Tree Construction

## Logical Structure

Breaking down the complex process description into the tree structure:

```
-> (
    'A',
    'RG',
    'IA',
    'TI',
    'TC',
    X( 'CE', 'FBP' ),
    * ( tau, -> ( 'SC', X( 'TM', 'SPT' ), X( 'FCE', 'FBA' ) ) ),
    + ( 'AI', 'NC' ),
    'FAS',
    'DDI',
    + ( 'BL', 'ICP', 'MRF' )
)
```

**Explanation of the loop construct (step 4):**
The `*(A, B)` operator executes `A` first, then either exits or executes `B` followed by `A` again. Here we set `A = tau` (representing the "check result" decision point — if normal, we exit immediately) and `B = -> (SC, X(TM,SPT), X(FCE,FBA))` (the abnormal-result treatment path). This correctly captures: possibly zero iterations (if first test is normal) or repeated iterations of Specialist Consultation  Treatment  Re-Diagnostic Test until a normal result is reached.

## Python Code

```python
from pm4py.objects.process_tree.obj import ProcessTree, Operator

# Root: overall sequence
root = ProcessTree(operator=Operator.SEQUENCE)

# Leaf activities in the main sequence
A   = ProcessTree(label="A", parent=root)
RG  = ProcessTree(label="RG", parent=root)
IA  = ProcessTree(label="IA", parent=root)
TI  = ProcessTree(label="TI", parent=root)
TC  = ProcessTree(label="TC", parent=root)

# Step 3: exclusive choice of initial diagnostic test
init_test = ProcessTree(operator=Operator.XOR, parent=root)
CE  = ProcessTree(label="CE", parent=init_test)
FBP = ProcessTree(label="FBP", parent=init_test)
init_test.children.append(CE)
init_test.children.append(FBP)

# Step 4: loop block  *( tau, -> (SC, X(TM,SPT), X(FCE,FBA)) )
loop = ProcessTree(operator=Operator.LOOP, parent=root)

tau = ProcessTree(parent=loop)  # silent step (do-part / exit check)

body_seq = ProcessTree(operator=Operator.SEQUENCE, parent=loop)

SC = ProcessTree(label="SC", parent=body_seq)

treatment_choice = ProcessTree(operator=Operator.XOR, parent=body_seq)
TM  = ProcessTree(label="TM", parent=treatment_choice)
SPT = ProcessTree(label="SPT", parent=treatment_choice)
treatment_choice.children.append(TM)
treatment_choice.children.append(SPT)

rdt_choice = ProcessTree(operator=Operator.XOR, parent=body_seq)
FCE = ProcessTree(label="FCE", parent=rdt_choice)
FBA = ProcessTree(label="FBA", parent=rdt_choice)
rdt_choice.children.append(FCE)
rdt_choice.children.append(FBA)

body_seq.children.append(SC)
body_seq.children.append(treatment_choice)
body_seq.children.append(rdt_choice)

loop.children.append(tau)       # "do" part (A)
loop.children.append(body_seq)  # "redo" part (B)

# Step 5: parallel Advanced Imaging / Nutritional Counseling
imaging_support = ProcessTree(operator=Operator.PARALLEL, parent=root)
AI = ProcessTree(label="AI", parent=imaging_support)
NC = ProcessTree(label="NC", parent=imaging_support)
imaging_support.children.append(AI)
imaging_support.children.append(NC)

# Step 6: final administrative/info sequence
FAS = ProcessTree(label="FAS", parent=root)
DDI = ProcessTree(label="DDI", parent=root)

# Step 7: parallel billing / insurance / records
final_admin = ProcessTree(operator=Operator.PARALLEL, parent=root)
BL  = ProcessTree(label="BL", parent=final_admin)
ICP = ProcessTree(label="ICP", parent=final_admin)
MRF = ProcessTree(label="MRF", parent=final_admin)
final_admin.children.append(BL)
final_admin.children.append(ICP)
final_admin.children.append(MRF)

# Assemble root children in order
root.children.append(A)
root.children.append(RG)
root.children.append(IA)
root.children.append(TI)
root.children.append(TC)
root.children.append(init_test)
root.children.append(loop)
root.children.append(imaging_support)
root.children.append(FAS)
root.children.append(DDI)
root.children.append(final_admin)
```

## Summary of Tree (textual notation)

```
-> (
    A,
    RG,
    IA,
    TI,
    TC,
    X( CE, FBP ),
    * ( tau,
        -> ( SC,
             X( TM, SPT ),
             X( FCE, FBA )
           )
      ),
    + ( AI, NC ),
    FAS,
    DDI,
    + ( BL, ICP, MRF )
)
```

This structure faithfully captures:
- The strictly sequential intake/triage/discharge flow.
- The exclusive choice between cardiovascular vs. general diagnostic paths (both initially and during re-diagnostics).
- The iterative "abnormal result" loop (Specialist Consultation  Treatment choice  Re-Diagnostic Test) that repeats until normal results are obtained, modeled via the LOOP operator with a silent (`tau`) exit condition.
- The two concurrency blocks: (AI, NC) and (BL, ICP, MRF), reflecting activities that can happen in true concurrency without a fixed order.
