## Modeling the process

**Step by step mapping**

| Description | Processtree fragment |
|---|---|
| Arrival  Registration  Intake (1) | `'A', 'RG', 'IA'` (sequence) |
| Triage (2) | `'TI', 'TC'` (sequence) |
| Initial test (3) | `X( 'CE', 'FBP' )` |
| Abnormalresult cycle (4) | `* ( tau, -> ( 'SC', X('TM','SPT'), X('FCE','FBA') ) )` – the "do" part is a **tau** so the body may be executed 0, 1, 2, … times (the RDT step *is* the exclusive choice `X('FCE','FBA')`) |
| Imaging + counselling (5) | `+ ( 'AI', 'NC' )` |
| Administrative info (6) | `'FAS', 'DDI'` (sequence) |
| Financial/records clearance (7) | `+ ( 'BL', 'ICP', 'MRF' )` |

**Resulting process tree**

```
-> ( 'A', 'RG', 'IA', 'TI', 'TC',
     X ( 'CE', 'FBP' ),
     * ( tau, -> ( 'SC', X ( 'TM', 'SPT' ), X ( 'FCE', 'FBA' ) ) ),
     + ( 'AI', 'NC' ),
     'FAS', 'DDI',
     + ( 'BL', 'ICP', 'MRF' ) )
```

## pm4py construction

```python
from pm4py.objects.process_tree.obj import ProcessTree, Operator

# ------------------------------------------------------------------ root
root = ProcessTree(operator=Operator.SEQUENCE)

# 1) arrival, registration, intake   2) triage
A   = ProcessTree(label="A",  parent=root)
RG  = ProcessTree(label="RG", parent=root)
IA  = ProcessTree(label="IA", parent=root)
TI  = ProcessTree(label="TI", parent=root)
TC  = ProcessTree(label="TC", parent=root)

# 3) initial diagnostic test: X ( CE, FBP )
init_test = ProcessTree(operator=Operator.XOR, parent=root)
CE  = ProcessTree(label="CE",  parent=init_test)
FBP = ProcessTree(label="FBP", parent=init_test)
init_test.children.append(CE)
init_test.children.append(FBP)

# 4) loop:  * ( tau , -> ( SC, X(TM,SPT), X(FCE,FBA) ) )
loop = ProcessTree(operator=Operator.LOOP, parent=root)

tau_do = ProcessTree(label=None, parent=loop)          # silent step -> loop may be skipped

loop_body = ProcessTree(operator=Operator.SEQUENCE, parent=loop)

SC = ProcessTree(label="SC", parent=loop_body)

treatment = ProcessTree(operator=Operator.XOR, parent=loop_body)   # TM or SPT
TM  = ProcessTree(label="TM",  parent=treatment)
SPT = ProcessTree(label="SPT", parent=treatment)
treatment.children.append(TM)
treatment.children.append(SPT)

rdt = ProcessTree(operator=Operator.XOR, parent=loop_body)         # RDT = X(FCE, FBA)
FCE = ProcessTree(label="FCE", parent=rdt)
FBA = ProcessTree(label="FBA", parent=rdt)
rdt.children.append(FCE)
rdt.children.append(FBA)

loop_body.children.append(SC)
loop_body.children.append(treatment)
loop_body.children.append(rdt)

loop.children.append(tau_do)
loop.children.append(loop_body)

# 5) + ( AI, NC )
par_support = ProcessTree(operator=Operator.PARALLEL, parent=root)
AI = ProcessTree(label="AI", parent=par_support)
NC = ProcessTree(label="NC", parent=par_support)
par_support.children.append(AI)
par_support.children.append(NC)

# 6) FAS then DDI
FAS = ProcessTree(label="FAS", parent=root)
DDI = ProcessTree(label="DDI", parent=root)

# 7) + ( BL, ICP, MRF )
par_admin = ProcessTree(operator=Operator.PARALLEL, parent=root)
BL  = ProcessTree(label="BL",  parent=par_admin)
ICP = ProcessTree(label="ICP", parent=par_admin)
MRF = ProcessTree(label="MRF", parent=par_admin)
par_admin.children.append(BL)
par_admin.children.append(ICP)
par_admin.children.append(MRF)

# ------------------------------------------------- attach to the root (in order)
root.children.append(A)
root.children.append(RG)
root.children.append(IA)
root.children.append(TI)
root.children.append(TC)
root.children.append(init_test)
root.children.append(loop)
root.children.append(par_support)
root.children.append(FAS)
root.children.append(DDI)
root.children.append(par_admin)

print(root)
```

Printing yields:

```
->( 'A', 'RG', 'IA', 'TI', 'TC', X( 'CE', 'FBP' ),
    *( tau, ->( 'SC', X( 'TM', 'SPT' ), X( 'FCE', 'FBA' ) ) ),
    +( 'AI', 'NC' ), 'FAS', 'DDI', +( 'BL', 'ICP', 'MRF' ) )
```

**Example trace (one abnormal cycle, cardiac branch):**
`A, RG, IA, TI, TC, CE, SC, TM, FCE, NC, AI, FAS, DDI, ICP, BL, MRF`

*(If you want `RDT` to appear as an explicit recorded activity, simply replace the `rdt` XOR node in the loop body by `-> ( 'RDT', X('FCE','FBA') )`.)*
