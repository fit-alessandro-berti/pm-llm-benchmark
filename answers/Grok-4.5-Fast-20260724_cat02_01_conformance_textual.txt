**Violating cases: 2, 3, and 5.**

### Case 1 (compliant)
Sequence: Receive order → Check inventory → Authorize payment → Package items → Ship order → Close order.  
This exactly matches the expected “inventory sufficient” path.

### Case 2 (violates)
Sequence: Receive order → Check inventory → Package items → Authorize payment → Ship order → Close order.  
- **Package items** occurs *before* **Authorize payment**.  
The normative description requires authorization only after the inventory check *and before packaging* (“Authorize payment should only occur after Check inventory and before packaging”; “Package items should only occur after authorization”). Packaging before payment authorization is explicitly listed as a violation.

### Case 3 (violates)
Sequence: Receive order → Check inventory → Authorize payment → Cancel order → Ship order → Close order.  
- After an inventory check that leads to cancellation, the process should go directly to **Cancel order** then **Close order**. Authorization, packaging, and shipping are not part of the insufficient-inventory branch.  
- **Ship order** occurs *after* **Cancel order**. The description states that shipping must never follow a cancellation and that fulfillment activities are illogical once an order is canceled.  
- Authorization itself is also out of place once the path has branched to cancellation.

### Case 4 (compliant)
Sequence: Receive order → Check inventory → Cancel order → Close order.  
This exactly matches the expected “inventory insufficient” path.

### Case 5 (violates)
Sequence: Receive order → Check inventory → Authorize payment → Ship order → Close order.  
- **Ship order** occurs without a preceding **Package items**. The normative description requires packaging after authorization and before shipping (“Package items should only occur after authorization and before shipping”; “Ship order should only occur after packaging”). Shipping without packaging is a clear deviation.

In short, Cases 1 and 4 follow the described happy path or cancellation path; Cases 2, 3, and 5 break the ordering, branching, or mandatory-activity constraints stated in the normative text.
