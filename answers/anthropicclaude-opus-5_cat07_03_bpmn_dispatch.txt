## Overview

This is a **BPMN 2.0 process diagram** titled **“Dispatch of goods”**, modelled inside a single pool named **“Computer Hardware Shop.”** The pool is divided into three horizontal lanes (roles):

1. **Logistics** (top)
2. **Secretary** (middle)
3. **Warehouse** (bottom)

## Flow of the process

**Start:** A start event labelled **“Ship goods”** sits in the Secretary lane. It leads immediately into a **parallel gateway (AND-split)**, which opens two concurrent branches — one handled by the Secretary, one by the Warehouse.

### Branch A – Secretary (shipment arrangement)

- **“Clarify shipment method”**  an **exclusive gateway (XOR)** labelled **“Special handling?”**
  - **“yes”** path: **“Get 3 offers from logistic companies”**  **“Select logistic company and place order”**  joins the XOR merge on the right.
  - **“no”** path: **“Check if insurance is required.”** This task is supported by two artifacts: a **data object “Order details”** and a **data store “Customer information”**, connected by a dashed association.
    - It then flows into an **inclusive gateway (OR-split)** with two outgoing paths:
      - **“If insurance necessary”**  up into the **Logistics** lane to the task **“Insure parcel.”**
      - **“always”**  **“Write package label”** (in the Secretary lane).
    - Both paths reconverge at a second **inclusive gateway (OR-join)**.
  - Both the “yes” and “no” routes then merge at an **exclusive gateway (XOR-merge)**, whose output drops down into the Warehouse lane.

### Branch B – Warehouse (physical packaging)

- **“Package goods”**, which carries an **attached (interrupting) timer boundary event labelled “48 hours.”**
  - If the timer fires, the flow goes to **“Notify customer about delay”**, which then rejoins the main flow at an **inclusive gateway**.
  - The normal completion of “Package goods” also flows to that same gateway.

### Synchronisation and end

Both branches meet at a **parallel gateway (AND-join)** in the Warehouse lane, after which:

**“Fill out Shipment paperwork”**  **“Move package to pickup area”**  **end event “Shipment prepared.”**

## Visual style

Rounded rectangles for tasks, diamonds for gateways ( for parallel,  for exclusive,  for inclusive), thin circles for the start event and a thick circle for the end event, solid arrows for sequence flow, and a dotted line for the data association. All text is dark blue/brown on a white background, with the pool and lane labels rotated vertically along the left edge.
