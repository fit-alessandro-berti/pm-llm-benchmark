Let `` denote a `SilentTransition`.

```text
OR -> MS -> QS
   -> *( AS, *( IQC,  ) )
   -> *( TST, RT )
   -> PK
   -> X( LB,  )
   -> DP
   -> D
```

- `*( IQC,  )` means: one or more `IQC` checks can be repeated silently before another assembly round.
- `*( AS, *( IQC,  ) )` means: `AS` can happen once, or be repeated; between consecutive `AS` executions, one or more `IQC` checks occur.
- `*( TST, RT )` captures the re-testing loop.
- `X( LB,  )` captures that labeling is optional.

Equivalent Python object construction:

```python
from pm4py.objects.powl.obj import StrictPartialOrder, OperatorPOWL, Transition, SilentTransition
from pm4py.objects.process_tree.obj import Operator

OR = Transition("OR")
MS = Transition("MS")
QS = Transition("QS")
AS = Transition("AS")
IQC = Transition("IQC")
TST = Transition("TST")
RT = Transition("RT")
PK = Transition("PK")
LB = Transition("LB")
DP = Transition("DP")
D = Transition("D")

# One or more IQC checks: IQC, then possibly silently repeat IQC
iqc_repeat = OperatorPOWL(
    operator=Operator.LOOP,
    children=[IQC, SilentTransition()]
)

# AS may be repeated; before each repeated AS, one or more IQC checks happen
assembly_loop = OperatorPOWL(
    operator=Operator.LOOP,
    children=[AS, iqc_repeat]
)

# Testing and re-testing loop
testing_loop = OperatorPOWL(
    operator=Operator.LOOP,
    children=[TST, RT]
)

# Labeling optional
labeling_choice = OperatorPOWL(
    operator=Operator.XOR,
    children=[LB, SilentTransition()]
)

# Top-level partial order
root = StrictPartialOrder(
    nodes=[OR, MS, QS, assembly_loop, testing_loop, PK, labeling_choice, DP, D]
)

root.order.add_edge(OR, MS)
root.order.add_edge(MS, QS)
root.order.add_edge(QS, assembly_loop)
root.order.add_edge(assembly_loop, testing_loop)
root.order.add_edge(testing_loop, PK)
root.order.add_edge(PK, labeling_choice)
root.order.add_edge(labeling_choice, DP)
root.order.add_edge(DP, D)
```
