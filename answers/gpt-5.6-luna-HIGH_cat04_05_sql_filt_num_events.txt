```sql
WITH eligible_cases AS (
    SELECT
        case_id
    FROM event_log
    GROUP BY case_id
    HAVING COUNT(*) <= 6
)
SELECT e.*
FROM event_log AS e
JOIN eligible_cases AS c
    ON e.case_id = c.case_id;
```

The `HAVING` clause keeps only `case_id` values with six or fewer events, and the join returns all events belonging to those cases.
