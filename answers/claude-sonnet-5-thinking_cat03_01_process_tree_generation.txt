# Process Tree Construction

Looking at this complex hospital process, I need to identify the overall structure:

1. **Sequential backbone**: Arrival  Registration  Intake  Triage (2 steps)  Initial Test Choice  Diagnostic Loop  Parallel (Imaging/Nutrition)  Follow-up Sequence  Parallel (Admin/Billing)
2. **Initial diagnostic choice**: XOR(CE, FBP)
3. **Diagnostic loop**: This is a classic `*(A, B)` loop where:
   - `A` = `tau` (the "check results" / exit point — since the actual test already happened either as the initial test or as the RDT at the end of previous iteration)
   - `B` = the "abnormal result" branch: Specialist Consultation  Treatment Choice  Re-Diagnostic Test
4. **Advanced care**: PARALLEL(AI, NC)
5. **Final concurrency block**: PARALLEL(BL, ICP, MRF)

Here is the full construction:

```python
from pm4py.objects.process_tree.obj import ProcessTree, Operator

# ROOT: overall sequence
root = ProcessTree(operator=Operator.SEQUENCE)

# --- Leaf and intermediate nodes for the main sequence ---
A   = ProcessTree(label="A", parent=root)
RG  = ProcessTree(label="RG", parent=root)
IA  = ProcessTree(label="IA", parent=root)
TI  = ProcessTree(label="TI", parent=root)
TC  = ProcessTree(label="TC", parent=root)

# --- Initial diagnostic test: XOR(CE, FBP) ---
initial_test = ProcessTree(operator=Operator.XOR, parent=root)
CE  = ProcessTree(label="CE", parent=initial_test)
FBP = ProcessTree(label="FBP", parent=initial_test)
initial_test.children.append(CE)
initial_test.children.append(FBP)

# --- Diagnostic Loop: *(tau, SC -> XOR(TM,SPT) -> XOR(FCE,FBA)) ---
loop = ProcessTree(operator=Operator.LOOP, parent=root)

loop_exit = ProcessTree(operator=Operator.TAU, parent=loop)  # do-part: exit check (tau)

loop_body = ProcessTree(operator=Operator.SEQUENCE, parent=loop)  # redo-part
SC = ProcessTree(label="SC", parent=loop_body)

treatment_choice = ProcessTree(operator=Operator.XOR, parent=loop_body)
TM  = ProcessTree(label="TM", parent=treatment_choice)
SPT = ProcessTree(label="SPT", parent=treatment_choice)
treatment_choice.children.append(TM)
treatment_choice.children.append(SPT)

redo_test_choice = ProcessTree(operator=Operator.XOR, parent=loop_body)
FCE = ProcessTree(label="FCE", parent=redo_test_choice)
FBA = ProcessTree(label="FBA", parent=redo_test_choice)
redo_test_choice.children.append(FCE)
redo_test_choice.children.append(FBA)

loop_body.children.append(SC)
loop_body.children.append(treatment_choice)
loop_body.children.append(redo_test_choice)

loop.children.append(loop_exit)
loop.children.append(loop_body)

# --- Advanced Imaging & Nutritional Counseling: +(AI, NC) ---
ai_nc = ProcessTree(operator=Operator.PARALLEL, parent=root)
AI = ProcessTree(label="AI", parent=ai_nc)
NC = ProcessTree(label="NC", parent=ai_nc)
ai_nc.children.append(AI)
ai_nc.children.append(NC)

# --- Follow-up admin sequence ---
FAS = ProcessTree(label="FAS", parent=root)
DDI = ProcessTree(label="DDI", parent=root)

# --- Final concurrency block: +(BL, ICP, MRF) ---
final_parallel = ProcessTree(operator=Operator.PARALLEL, parent=root)
BL  = ProcessTree(label="BL", parent=final_parallel)
ICP = ProcessTree(label="ICP", parent=final_parallel)
MRF = ProcessTree(label="MRF", parent=final_parallel)
final_parallel.children.append(BL)
final_parallel.children.append(ICP)
final_parallel.children.append(MRF)

# --- Assemble the root's children in order ---
root.children.append(A)
root.children.append(RG)
root.children.append(IA)
root.children.append(TI)
root.children.append(TC)
root.children.append(initial_test)
root.children.append(loop)
root.children.append(ai_nc)
root.children.append(FAS)
root.children.append(DDI)
root.children.append(final_parallel)
```

## Explanation of key modeling decisions

**Textual notation equivalent:**

```
-> (
    'A', 'RG', 'IA', 'TI', 'TC',
    X( 'CE', 'FBP' ),
    * ( 
        tau, 
        -> ( 'SC', X('TM','SPT'), X('FCE','FBA') ) 
    ),
    + ( 'AI', 'NC' ),
    'FAS', 'DDI',
    + ( 'BL', 'ICP', 'MRF' )
)
```

- **The loop `*(tau, B)`**: The `do`-part is `tau` because the actual diagnostic test evaluation ("normal"/"abnormal") is not itself an activity — it's just the decision point. If results are normal, the loop exits immediately (zero iterations of `B`). If abnormal, `B` (Specialist Consultation  Treatment choice  Re-diagnostic test) executes, and then control returns to the `tau` check again, allowing repeated iterations until normal results are achieved.
- **XOR blocks** are used for CE/FBP, TM/SPT, and FCE/FBA since only one path is taken each time.
- **PARALLEL blocks** are used for AI/NC (concurrent advanced care) and BL/ICP/MRF (concurrent final clearance), reflecting true concurrency with no ordering constraints.
- The rest of the steps are strictly sequential, captured by nesting them as children of the top-level `SEQUENCE` node.
