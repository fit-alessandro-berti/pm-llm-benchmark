**This is a process-flow / process-mining style diagram** that visualizes how different document/item types move through a set of business activities (mostly order-to-cash and procure-to-pay related). It shows volumes (object counts), process steps, and transition times between steps.

### Main object types (sources at the top)
- **VendorInvoiceItem** (1.2M objects) — green path  
- **ReturnOrderItem** (0.8M objects) — red path  
- **PurchaseRequisitionItem** (2.0M objects) — purple path  
- **SalesOrderItem** (3.5M objects) — orange path  
- **PurchaseOrderItem** (5.0M objects) — blue path  

Each type begins at its own “Start” node and then joins the shared process network.

### Flow and timing highlights
- **Times on the arrows** are average or measured transition times (in milliseconds). Examples: 300 ms, 400 ms, 600 ms, 250 ms, etc.
- Multiple colored arrows enter/leave the same activity, showing that different document types share many of the same process steps.
- The diagram contains several **End** nodes, indicating different possible process completions (successful order closure, invoice creation, returns processing, etc.).
- Notable cross-flows:
  - Purchase-related items (purple/blue) heavily feed into Create/Approve Requisition → Send Order / Check Stock → Approve Payment → Create Invoice.
  - Sales-related items (orange) mainly follow Create Order → Pack Goods → Ship Goods → Confirm Delivery → Close Order.
  - Returns (red/green) interact with Approve Requisition, Process Return, and Close Order / Create Invoice.

### Overall meaning
This is a **multi-object process map** (common in process-mining tools such as Celonis, UiPath Process Mining, or similar platforms). It shows:

1. How five different business-object types participate in the same set of activities.
2. The volume of work at each step.
3. The speed of hand-offs between steps.
4. Where the different object types converge or diverge.

It is typically used for process discovery, bottleneck analysis, conformance checking, or understanding end-to-end order and invoice lifecycles across purchasing, sales, returns, and invoicing.
