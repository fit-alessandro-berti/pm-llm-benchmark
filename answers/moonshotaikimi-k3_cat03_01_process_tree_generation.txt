## Process tree

The complete patient journey is a single root **sequence**. The `RDT` stage is represented by the exclusive choice between `FCE` and `FBA`, since the re-diagnostic test itself is one of those two alternatives.

```text
->(
    'A',
    'RG',
    'IA',
    ->(
        'TI',
        'TC'
    ),
    X(
        'CE',
        'FBP'
    ),
    *(
        ->(
            'SC',
            X(
                'TM',
                'SPT'
            ),
            X(
                'FCE',
                'FBA'
            )
        ),
        tau
    ),
    +(
        'AI',
        'NC'
    ),
    ->(
        'FAS',
        'DDI'
    ),
    +(
        'BL',
        'ICP',
        'MRF'
    )
)
```

Here, the loop body is:

```text
->('SC', X('TM', 'SPT'), X('FCE', 'FBA'))
```

and:

```text
*(loop_body, tau)
```

means that the consultation, one selected treatment, and one selected re-diagnostic test occur; the loop can then either exit or silently return to another specialist consultation.

The sequence and parallel operators are shown as n-ary operators. This is equivalent to nesting binary operators.

## Equivalent PM4Py construction

```python
from pm4py.objects.process_tree.obj import ProcessTree, Operator


def activity(label):
    return ProcessTree(label=label)


def tau():
    # In PM4Py, an unlabeled leaf represents a silent step.
    return ProcessTree(label=None)


def make_node(operator, *children):
    node = ProcessTree(operator=operator)

    for child in children:
        # Both links must be established explicitly.
        child.parent = node
        node.children.append(child)

    return node


# Initial stages
triage = make_node(
    Operator.SEQUENCE,
    activity("TI"),
    activity("TC")
)

initial_diagnostic = make_node(
    Operator.XOR,
    activity("CE"),
    activity("FBP")
)

# Abnormal-results loop
treatment_choice = make_node(
    Operator.XOR,
    activity("TM"),
    activity("SPT")
)

# This XOR represents the RDT stage.
re_diagnostic_test = make_node(
    Operator.XOR,
    activity("FCE"),
    activity("FBA")
)

loop_body = make_node(
    Operator.SEQUENCE,
    activity("SC"),
    treatment_choice,
    re_diagnostic_test
)

abnormal_results_loop = make_node(
    Operator.LOOP,
    loop_body,
    tau()
)

# Parallel recovery-support activities
recovery_support = make_node(
    Operator.PARALLEL,
    activity("AI"),
    activity("NC")
)

# Final informational sequence
final_patient_steps = make_node(
    Operator.SEQUENCE,
    activity("FAS"),
    activity("DDI")
)

# Parallel administrative and financial clearances
final_clearance = make_node(
    Operator.PARALLEL,
    activity("BL"),
    activity("ICP"),
    activity("MRF")
)

# Root process tree
root = make_node(
    Operator.SEQUENCE,
    activity("A"),
    activity("RG"),
    activity("IA"),
    triage,
    initial_diagnostic,
    abnormal_results_loop,
    recovery_support,
    final_patient_steps,
    final_clearance
)

root.parent = None
```

The tree above executes the remediation loop at least once, corresponding to the abnormal-results path. If the model must also allow the initial diagnostic result to be normal and therefore skip the loop entirely, the loop node can instead be wrapped as:

```text
X(
    tau,
    *(
        ->('SC', X('TM', 'SPT'), X('FCE', 'FBA')),
        tau
    )
)
```

Basic process trees do not explicitly store data guards such as “abnormal,” “normal,” “cardiac,” or “non-cardiac”; those conditions annotate the corresponding choices rather than appearing as additional activities.
