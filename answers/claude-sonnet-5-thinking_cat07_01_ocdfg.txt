# Process Mining Visualization Description

This is a **multi-process flowchart** (likely from process mining/object-centric process mining software) that shows how five different business object types flow through interconnected process activities. It appears to represent an integrated **Order-to-Cash / Procure-to-Pay** business process.

## Object Types (Top Row)
Five data sources feed into the process, each showing object counts:
- **VendorInvoiceItem** (1.2M objects) — teal/green
- **ReturnOrderItem** (0.8M objects) — red
- **PurchaseRequisitionItem** (2.0M objects) — purple
- **SalesOrderItem** (3.5M objects) — orange
- **PurchaseOrderItem** (5.0M objects) — blue

## Structure
- Each object type starts at its own **Start** node and flows through color-coded paths.
- **Activity boxes** (e.g., "Create Requisition," "Approve Requisition," "Send Order," "Pack Goods," etc.) show an **"Overall" count** (total objects passing through) and colored dots indicating which object type(s) interact with that step.
- **Edges are labeled with timing metrics** (in milliseconds), representing average duration or throughput time between activities.
- Multiple colored lines can converge on shared activities (e.g., "Approve Requisition" receives purple, blue, teal, and red flows), showing where different object types intersect in a shared process step.

## Two Main Branches
1. **Procurement side** (left): Create Requisition  Approve Requisition  Send Order/Check Stock  Approve Payment  Create Invoice  End
2. **Sales/Fulfillment side** (right): Create Order  Pack Goods  Ship Goods  Confirm Delivery  Close Order  End

There's also a **Process Return** branch handling returned orders, linking back into the requisition approval flow.

## Purpose
This diagram is characteristic of **object-centric process mining (OCPM)**, used to visualize how multiple related entities (orders, invoices, returns, requisitions) share common process steps, helping analysts identify bottlenecks (via ms timings) and cross-object dependencies within an ERP-like workflow (e.g., SAP).
