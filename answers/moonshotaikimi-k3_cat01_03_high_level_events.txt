## 1. Grouping Methodology

I applied five complementary criteria to segment each case's event sequence:

| Criterion | Signal in the Log |

| **Resource continuity** | Consecutive events by the same operator/machine (e.g., Operator B's tool pickup  welds) tend to belong to one step. |
| **Functional coherence** | Each event was tagged by intent: *handling, identification, positioning, conditioning, joining, verification, surface treatment, curing*. Events with compatible intents were merged. |
| **Causal dependency** | Tightly coupled action pairs ("pick up tool  weld", "apply coating  dry") were kept in the same group. |
| **Product state change** | Distinguishing whether an event *transforms* the product (welding, coating), *prepares* it (aligning, preheating), or merely *verifies* it (measuring, checking). |
