Here is a complete DuckDB query that builds the ordered trace per case, counts unique traces, picks the topK, and returns the full original events for those cases.

```sql
WITH 
-- 1. Set K (replace 5 with whatever topK you need)
params AS (SELECT 5 AS k),

-- 2. Ordered activity sequence for each case
case_variant AS (
  SELECT 
    case_id,
    -- concatenate activities in timestamp order
    string_agg(activity, '|' ORDER BY timestamp) AS variant
  FROM event_log
  GROUP BY case_id
),

-- 3. Count cases per unique variant
variant_stats AS (
  SELECT 
    variant,
    COUNT(*) AS case_count
  FROM case_variant
  GROUP BY variant
),

-- 4. Select the top K variants by frequency
top_variants AS (
  SELECT variant
  FROM (
    SELECT 
      variant,
      row_number() OVER (ORDER BY case_count DESC) AS rn
    FROM variant_stats
  ) ranked
  WHERE rn <= (SELECT k FROM params)
)

-- 5. Return all original events that belong to cases in topK variants
SELECT e.*
FROM event_log e
INNER JOIN case_variant cv 
  ON e.case_id = cv.case_id
INNER JOIN top_variants tv 
  ON cv.variant = tv.variant
ORDER BY e.case_id, e.timestamp;
```

### How it works

| Step | CTE | Purpose |
|------|-----|---------|
| **case_variant** | `string_agg(... ORDER BY timestamp)` | Builds the ordered process variant (`activity|activity|...`) for each `case_id`. |
| **variant_stats** | `GROUP BY variant` | Aggregates variants and counts how many cases follow each one. |
| **top_variants** | `row_number() OVER (ORDER BY case_count DESC)` | Ranks variants by frequency and keeps only the top **K** (driven by the `params` CTE). |
| **Final SELECT** | `INNER JOIN` back to `event_log` | Keeps **only** events whose `case_id` maps to a topK variant; all other cases are excluded. |

**Notes / customization**
- Change `SELECT 5 AS k` to your desired **K**.
- The delimiter `|` can be replaced with any separator that does not appear inside your `activity` names.
- If `timestamp` can tie, add a secondary sort key (e.g., `ORDER BY timestamp, some_event_id`) inside the `string_agg` to make the sequence deterministic.
