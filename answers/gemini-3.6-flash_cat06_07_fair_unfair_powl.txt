Here are the python POWL models representing the hiring process at GlobalTeq Solutions: the first model includes the biased XOR branch, and the second model ensures a fair, standardized process for all candidates.

---

### 1. POWL Model with Potential Unfairness

In this model, after completing the skill assessment, candidates enter an XOR choice between a standard cultural fit evaluation (`CulturalFitCheck`) and an affiliation-based branch (`CommunityAffiliationCheck`). This XOR path provides implicit advantages/score adjustments for candidates with specific affiliations or local residency, introducing subtle unfairness into the workflow.

```python
import pm4py
from pm4py.objects.powl.obj import (
    OperatorPOWL,
    SilentTransition,
    StrictPartialOrder,
    Transition,
)
from pm4py.objects.process_tree.obj import Operator

# Define activities
receive_app = Transition(label="ReceiveApplication")
data_check = Transition(label="DataCompletenessCheck")
request_info = Transition(label="RequestMoreInfo")
skill_assess = Transition(label="SkillAssessment")
cultural_fit = Transition(label="CulturalFitCheck")
community_check = Transition(label="CommunityAffiliationCheck")
managerial_review = Transition(label="ManagerialReview")
final_decision = Transition(label="FinalDecision")

# Loop for resume parsing & missing information check
loop_data = OperatorPOWL(
    operator=Operator.LOOP, children=[data_check, request_info]
)

# XOR choice introducing potential bias (Standard Cultural Fit vs. Community Affiliation Uplift)
biased_cultural_choice = OperatorPOWL(
    operator=Operator.XOR, children=[cultural_fit, community_check]
)

# Define the overall partially ordered process
powl_model_unfair = StrictPartialOrder(
    nodes=[
        receive_app,
        loop_data,
        skill_assess,
        biased_cultural_choice,
        managerial_review,
        final_decision,
    ]
)

# Add control-flow order (sequential dependencies)
powl_model_unfair.order.add_edge(receive_app, loop_data)
powl_model_unfair.order.add_edge(loop_data, skill_assess)
powl_model_unfair.order.add_edge(skill_assess, biased_cultural_choice)
powl_model_unfair.order.add_edge(biased_cultural_choice, managerial_review)
powl_model_unfair.order.add_edge(managerial_review, final_decision)
```

---

### 2. POWL Model Without Unfairness

In this fair version of the process, the XOR choice and the selective `CommunityAffiliationCheck` activity are removed. All candidates proceed through the exact same standard `CulturalFitCheck` without shortcutting or conditional score uplifts based on local community membership or elite club affiliations.

```python
import pm4py
from pm4py.objects.powl.obj import (
    OperatorPOWL,
    SilentTransition,
    StrictPartialOrder,
    Transition,
)
from pm4py.objects.process_tree.obj import Operator

# Define activities
receive_app = Transition(label="ReceiveApplication")
data_check = Transition(label="DataCompletenessCheck")
request_info = Transition(label="RequestMoreInfo")
skill_assess = Transition(label="SkillAssessment")
cultural_fit = Transition(label="CulturalFitCheck")
managerial_review = Transition(label="ManagerialReview")
final_decision = Transition(label="FinalDecision")

# Loop for resume parsing & missing information check
loop_data = OperatorPOWL(
    operator=Operator.LOOP, children=[data_check, request_info]
)

# Define the overall standardized, fair process
powl_model_fair = StrictPartialOrder(
    nodes=[
        receive_app,
        loop_data,
        skill_assess,
        cultural_fit,
        managerial_review,
        final_decision,
    ]
)

# Add control-flow order (sequential dependencies)
powl_model_fair.order.add_edge(receive_app, loop_data)
powl_model_fair.order.add_edge(loop_data, skill_assess)

```
