```sql
SELECT e.*
FROM event_log AS e
JOIN (
    SELECT case_id
    FROM event_log
    GROUP BY case_id
    HAVING COUNT(*) <= 6
) AS valid_cases
    ON e.case_id = valid_cases.case_id;
```

This groups events by `case_id`, retains only cases with six or fewer events, and joins those case IDs back to the original table to return all corresponding event rows.
