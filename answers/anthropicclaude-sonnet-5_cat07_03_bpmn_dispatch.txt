# BPMN Process Diagram Description

This is a **Business Process Model and Notation (BPMN)** diagram depicting the **"Dispatch of Goods"** process for a **Computer Hardware Shop**. It's organized into three swimlanes representing different roles/departments:

## Swimlanes
1. **Logistics** (top)
2. **Secretary** (middle)
3. **Warehouse** (bottom)

## Process Flow

**Start:** The process begins with a **"Ship goods"** start event, triggering a parallel split (AND gateway).

### Secretary Lane
- **Clarify shipment method**
- Decision: **"Special handling?"**
  - If **No**  proceeds to check insurance
  - If **Yes**  **Get 3 offers from logistic companies**  **Select logistic company and place order**
- **Check if insurance is required** (references "Order details" and "Customer information" database)
- Decision gateway: **"If insurance necessary"**
  - **Always** path leads to **Write package label**
- These paths converge before merging with the Warehouse lane

### Logistics Lane
- **Insure parcel** (triggered when insurance is needed, then loops back to the main flow)

### Warehouse Lane (parallel branch)
- **Package goods**
- A timer event (**48 hours**) can trigger **Notify customer about delay** if packaging takes too long
- Both paths converge at an event-based gateway
- Joins with Secretary's output via an AND gateway (synchronization)
- **Fill out Shipment paperwork**
- **Move package to pickup area**

**End:** The process concludes with **"Shipment prepared"** end event.

## Key BPMN Elements Used
- **Gateways:** Exclusive (X), Parallel (+), and Event-based (pentagon) gateways
- **Data objects:** Order details (document), Customer information (database)
- **Events:** Start, intermediate timer event, and end event
- **Tasks:** Rounded rectangles representing individual activities

This diagram effectively illustrates parallel processing (packaging and paperwork happening simultaneously) with conditional branching for special handling and insurance requirements.
