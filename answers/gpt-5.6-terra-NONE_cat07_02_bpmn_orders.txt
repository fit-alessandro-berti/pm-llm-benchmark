The visualization is a BPMN-style cross-functional workflow for processing a customer order across four departments: **Sales, Production, Procurement, and Warehouse**.

### Sales
- The process starts with a **“Morning meeting”** event.
- Sales **checks order completeness** and then **checks whether the customer is already in the database**.
- A decision gateway determines:
  - If the customer is **not in the database**, Sales **adds the customer to the database**.
  - If the customer is already present, the flow continues directly.
- Sales then **sends order details** to the other departments.
- After the product is sent, Sales receives a **“Product sent”** message and **drafts an invoice**, ending the Sales process.

### Production
- Production receives the **order details**.
- It enters a gateway and proceeds to **plan production**.
- Another gateway leads to **manufacture product**.
- If there is a **material-not-fully-available** issue, a message is sent to Procurement.
- Once manufacturing is done, Production sends a **“Product complete”** message to Warehouse.

### Procurement
- Procurement receives the order details as well.
- It contains a **Material Compensation Subprocess**:
  - **Order materials**
  - If needed, **return material** is involved.
- Procurement then **checks materials**.
- If materials are available/handled, it sends a response or material-related message back to Production.
- There is also an **order cancellation** message path that ends the Procurement process.

### Warehouse
- Warehouse receives the **“Product complete”** message from Production.
- It performs **“Send product”**.
- It then sends a **“Product sent”** notification back to Sales.

### Overall flow
The diagram shows that Sales initiates and coordinates the order. Production manufactures the product, Procurement supports production when materials are insufficient, Warehouse dispatches the finished product, and Sales then prepares the invoice. Dashed lines represent inter-department message flows, while solid arrows show the internal sequence of work within each department.
