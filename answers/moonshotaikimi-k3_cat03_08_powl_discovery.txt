Equivalent Python-like construction:

```python
import pm4py
from pm4py.objects.powl.obj import StrictPartialOrder, OperatorPOWL, Transition, SilentTransition
from pm4py.objects.process_tree.obj import Operator

OR  = Transition(label="OR")
MS  = Transition(label="MS")
QS  = Transition(label="QS")
AS  = Transition(label="AS")
IQC = Transition(label="IQC")
TST = Transition(label="TST")
RT  = Transition(label="RT")
PK  = Transition(label="PK")
LB  = Transition(label="LB")
DP  = Transition(label="DP")
D   = Transition(label="D")

tau_rep  = SilentTransition()
tau_skip = SilentTransition()

# One or more IQC events before returning to AS.
# Needed because case 3 contains: AS IQC IQC AS IQC AS
iqc_plus = OperatorPOWL(operator=Operator.LOOP, children=[IQC, tau_rep])

# AS, then optionally: one/more IQC followed by AS again.
assemble = OperatorPOWL(operator=Operator.LOOP, children=[AS, iqc_plus])

# TST, then optionally: RT followed by TST again.
test = OperatorPOWL(operator=Operator.LOOP, children=[TST, RT])

# LB may be skipped.
label = OperatorPOWL(operator=Operator.XOR, children=[LB, tau_skip])

root = StrictPartialOrder(nodes=[OR, MS, QS, assemble, test, PK, label, DP, D])

edges = [
    (OR, MS),
    (MS, QS),
    (QS, assemble),
    (assemble, test),
    (test, PK),
    (PK, label),
    (label, DP),
    (DP, D),
]

for src, tgt in edges:
    root.order.add_edge(src, tgt)
```

No concurrency is added because every case follows the same global precedence; the variation is captured by the two loops and the optional labeling choice. If consecutive IQCs before AS were considered invalid, `iqc_plus` could be replaced by just `IQC`, but that simpler model would not replay case 3.
