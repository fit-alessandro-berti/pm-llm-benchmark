# BPMN Process Diagram Description

This is a **Business Process Model and Notation (BPMN)** diagram depicting an order fulfillment workflow across four organizational departments (represented as horizontal swimlanes/pools):

## Swimlanes (Departments):
1. **Sales**
2. **Production**
3. **Procurement**
4. **Warehouse**

## Process Flow:

### Sales Lane
- Triggered by a **timer event** ("Monday morning")
- **Check order for completeness**  **Check if customer is already in database**
- Contains a sub-process "**Check customer's order**" with a gateway that either:
  - Adds new customer to the database (if not found), or
  - Proceeds directly (if customer exists)
- Sends **order details** message to both Production and Procurement
- Waits for a **"Product sent"** message signal
- Concludes with **Draft invoice**

### Production Lane
- Receives **"Order details arrive"** message
- **Plan production**  **Manufacture product**
- Includes a loop back to check "**Material not faulty**" before finalizing
- Ends with **"Product complete"** message event

### Procurement Lane
- Receives **"Order details arrive"** message
- Contains a **Material Compensation Subprocess**:
  - **Order materials**, with option to **Return material** (compensation activity)
- **Check materials** — includes a **timer/escalation** boundary event
- Can result in **Order cancellation** or proceed forward

### Warehouse Lane
- Receives **"Product complete"** message
- **Send product** activity
- Emits **"Product sent"** message (looped back to Sales)

## Key BPMN Elements Used:
- **Message flows** (dashed arrows) connecting different pools
- **Gateways**: exclusive (X) and parallel (+) 
- **Events**: start (circle), end (bold circle), intermediate message events, timer events, and cancellation events
- **Data store** symbol (database icon)
- **Compensation subprocess** with dotted-line compensation trigger

This diagram models a cross-functional business process showing how a customer order triggers coordinated activities across sales, manufacturing, procurement, and shipping departments, complete with error/cancellation handling and material return compensation logic.
