```
->(
    'Receive Application (RA)',
    'Validate Form (VF)',
    'Assess Eligibility (AE)',
    *(
        'Request Missing Info (RMI)',
        'Validate Form (VF)'
    ),
    'Approval Decision (AD)',
    'Send Confirmation (SC)',
    'Archive Case (AC)'

```

This represents the main sequence, with the loop allowing zero or more repetitions of:

```
'Request Missing Info (RMI)' -> 'Validate Form (VF)'
```

before the process proceeds to approval.
