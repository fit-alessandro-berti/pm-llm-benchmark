### Process-tree notation

```text
->(
    'A',
    'RG',
    'IA',
    'TI',
    'TC',
    X(
        'CE',
        'FBP'
    ),
    X(
        tau,
        *(
            ->(
                'SC',
                X(
                    'TM',
                    'SPT'
                ),
                'RDT',
                X(
                    'FCE',
                    'FBA'
                )
            ),
            tau
        )
    ),
    +(
        'AI',
        'NC'
    ),
    'FAS',
    'DDI',
    +(
        'BL',
        'ICP',
        'MRF'
    )
)
```

The first `tau` represents normal initial diagnostic results, in which case no specialist-treatment cycle is needed. If the results are abnormal, the loop executes at least once. The loop’s second `tau` is the silent redo step: after each re-diagnostic cycle, the process either exits or silently starts another cycle.

`RDT` is modeled as an explicit activity followed by the choice between `FCE` and `FBA`, ensuring every activity in the expected set is represented.

### PM4Py construction

```python
from pm4py.objects.process_tree.obj import ProcessTree, Operator


def activity(label):
    return ProcessTree(label=label)


def silent():
    # A leaf with neither an operator nor a label represents tau.
    return ProcessTree()


def operator_node(operator, *children):
    node = ProcessTree(operator=operator)

    for child in children:
        # The parent must be explicitly assigned.
        child.parent = node
        node.children.append(child)

    return node


def sequence(*children):
    return operator_node(Operator.SEQUENCE, *children)


def exclusive_choice(*children):
    return operator_node(Operator.XOR, *children)


def parallel(*children):
    return operator_node(Operator.PARALLEL, *children)


def loop(body, redo):
    return operator_node(Operator.LOOP, body, redo)


# Initial diagnostic choice
initial_diagnostic = exclusive_choice(
    activity("CE"),
    activity("FBP")
)

# One specialist treatment and re-diagnostic cycle
treatment_cycle = sequence(
    activity("SC"),
    exclusive_choice(
        activity("TM"),
        activity("SPT")
    ),
    activity("RDT"),
    exclusive_choice(
        activity("FCE"),
        activity("FBA")
    )
)

# If the initial result is normal, take tau.
# Otherwise, execute one or more treatment cycles.
result_handling = exclusive_choice(
    silent(),
    loop(
        treatment_cycle,
        silent()
    )
)

# Advanced imaging and lifestyle support
advanced_support = parallel(
    activity("AI"),
    activity("NC")
)

# Final administrative and financial clearances
final_clearance = parallel(
    activity("BL"),
    activity("ICP"),
    activity("MRF")
)

# Complete process tree
root = sequence(
    activity("A"),
    activity("RG"),
    activity("IA"),
    activity("TI"),
    activity("TC"),
    initial_diagnostic,
    result_handling,
    advanced_support,
    activity("FAS"),
    activity("DDI"),
    final_clearance
)
```

Here, `root` is the complete `ProcessTree` object, and every attached child has its `parent` property explicitly assigned.
