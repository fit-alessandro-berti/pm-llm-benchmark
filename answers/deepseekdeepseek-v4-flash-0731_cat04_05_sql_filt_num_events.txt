```sql
WITH qualifying_cases AS (
    SELECT case_id
    FROM event_log
    GROUP BY case_id
    HAVING COUNT(*) <= 6
)
SELECT e.*
FROM event_log e
JOIN qualifying_cases qc
    ON e.case_id = qc.case_id;
```

This counts the number of events per `case_id`, keeps only cases with **6 or fewer** events, and then returns all events from those cases.

If you prefer a window-based version:

```sql
SELECT *
FROM (
    SELECT *,
           COUNT(*) OVER (PARTITION BY case_id) AS event_count
    FROM event_log
)
WHERE event_count <= 6;
```
