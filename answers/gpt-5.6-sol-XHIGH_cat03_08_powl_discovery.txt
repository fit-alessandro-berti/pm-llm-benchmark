### Final POWL structure

Define the composite stages as follows:

- `IQC_BLOCK = *(IQC, )`  
  Produces one or more consecutive IQC activities.
- `ASSEMBLY_STAGE = *(AS, IQC_BLOCK)`  
  Produces `AS (IQC+ AS)*`, allowing no IQC, one IQC, or repeated IQCs followed by reassembly.
- `TEST_STAGE = *(TST, RT)`  
  Produces `TST (RT TST)*`.
- `LABEL_STAGE = X(LB, )`  
  Makes labeling optional.

Thus, symbolically:

```text
PO=(
  nodes={
    OR,
    MS,
    QS,
    *(AS, *(IQC, )),
    *(TST, RT),
    PK,
    X(LB, ),
    DP,
    D
  },
  order=TC({
    OR --> MS,
    MS --> QS,
    QS --> *(AS, *(IQC, )),
    *(AS, *(IQC, )) --> *(TST, RT),
    *(TST, RT) --> PK,
    PK --> X(LB, ),
    X(LB, ) --> DP,
    DP --> D
  })
)
```

Here, `TC` denotes the transitive closure of the listed ordering constraints.

### PM4Py construction

```python
from pm4py.objects.powl.obj import (
    StrictPartialOrder,
    OperatorPOWL,
    Transition,
    SilentTransition
)
from pm4py.objects.process_tree.obj import Operator

# Visible activities
order_received = Transition(label="OR")
material_sourcing = Transition(label="MS")
quality_screening = Transition(label="QS")
assembly = Transition(label="AS")
in_line_check = Transition(label="IQC")
testing = Transition(label="TST")
retesting = Transition(label="RT")
packaging = Transition(label="PK")
labeling = Transition(label="LB")
distribution_planning = Transition(label="DP")
dispatch = Transition(label="D")

# Separate silent transitions for separate purposes
tau_iqc_repeat = SilentTransition()
tau_skip_label = SilentTransition()

# One or more consecutive IQCs:
# IQC, or IQC tau IQC, or IQC tau IQC tau IQC, ...
iqc_block = OperatorPOWL(
    operator=Operator.LOOP,
    children=[in_line_check, tau_iqc_repeat]
)

# AS followed by zero or more rounds of:
# one-or-more IQCs, then AS again
assembly_stage = OperatorPOWL(
    operator=Operator.LOOP,
    children=[assembly, iqc_block]
)

# Initial test followed by zero or more RT/TST cycles
testing_stage = OperatorPOWL(
    operator=Operator.LOOP,
    children=[testing, retesting]
)

# Optional labeling
labeling_stage = OperatorPOWL(
    operator=Operator.XOR,
    children=[labeling, tau_skip_label]
)

stages = [
    order_received,
    material_sourcing,
    quality_screening,
    assembly_stage,
    testing_stage,
    packaging,
    labeling_stage,
    distribution_planning,
    dispatch
]

root = StrictPartialOrder(nodes=stages)

# Add the transitive closure of the sequential stage ordering.
for i in range(len(stages)):
    for j in range(i + 1, len(stages)):
        root.order.add_edge(stages[i], stages[j])
```

The visible behavior is:

```text
OR MS QS
AS (IQC+ AS)*
TST (RT TST)*
PK
(LB or skip)
DP D
```

No top-level concurrency is introduced because all observed cases consistently follow this stage order.
