### **2. Detailed Case-by-Case Analysis & Explanations**

#### **Case 1: Conforms to Normative Process**
* **Sequence:** Receive order $\rightarrow$ Check inventory $\rightarrow$ Authorize payment $\rightarrow$ Package items $\rightarrow$ Ship order $\rightarrow$ Close order
* **Explanation:** Follows the exact, standard normative flow for an order with sufficient inventory. Every prerequisite activity occurs in the prescribed order.

---

#### **Case 2: Violates Sequence Rule (Packaging before Payment Authorization)**
* **Sequence:** Receive order $\rightarrow$ Check inventory $\rightarrow$ **Package items** $\rightarrow$ **Authorize payment** $\rightarrow$ Ship order $\rightarrow$ Close order
* **Violation:** 
  * "Package items" took place at 10:00, prior to "Authorize payment" at 10:30.
* **Normative Rule Violated:** The process description explicitly requires that *"Authorize payment"* must take place *before* packaging items (*"'Package items' should only occur after authorization and before shipping"*). Packaging items prior to payment authorization risks preparing an order that the customer may not be able to pay for.

---

#### **Case 3: Violates Multiple Rules (Shipping after Cancellation & Missing Packaging)**
* **Sequence:** Receive order $\rightarrow$ Check inventory $\rightarrow$ Authorize payment $\rightarrow$ **Cancel order** $\rightarrow$ **Ship order** $\rightarrow$ Close order
* **Violations:**
  1. **Shipping after Cancellation:** "Ship order" (10:30) occurs after "Cancel order" (10:00).
  2. **Missing Packaging Step:** The order moves straight from payment authorization/cancellation to shipping without a "Package items" step.
  3. **Inconsistent Cancellation Path:** Payment was authorized prior to cancellation, whereas the textual description notes that insufficient inventory should proceed directly from "Check inventory" to "Cancel order."
* **Normative Rule Violated:** The textual description states unequivocally that *"Ship order" should only occur after packaging and never after a cancellation.* Fulfilling/shipping an order that has already been canceled is a critical process failure.

---

#### **Case 4: Conforms to Normative Process**
* **Sequence:** Receive order $\rightarrow$ Check inventory $\rightarrow$ Cancel order $\rightarrow$ Close order
* **Explanation:** This case perfectly follows the designated cancellation path for an order where inventory is insufficient (Receive $\rightarrow$ Check $\rightarrow$ Cancel $\rightarrow$ Close).

---

#### **Case 5: Violates Process Completion Rule (Skipped Packaging)**
* **Sequence:** Receive order $\rightarrow$ Check inventory $\rightarrow$ Authorize payment $\rightarrow$ **[Missing Package Items]** $\rightarrow$ Ship order $\rightarrow$ Close order
* **Violation:**
  * The activity "Package items" is omitted entirely between "Authorize payment" and "Ship order."
* **Normative Rule Violated:** According to the description, *"Only after items have been properly packaged is it appropriate to proceed with 'Ship order.'"* Skipping the packaging phase bypasses the required fulfillment preparation step.
