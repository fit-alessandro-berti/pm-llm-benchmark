For this process the ideal trace is linear:

`RO -> CA -> RI -> PI -> QC -> PO -> GSL -> D -> IC -> RP`

`RP` is the only optional activity - the payment can still be open.
All other activities occur exactly `1` per case.

```python
RO = "RO"
CA = "CA"
RI = "RI"
PI = "PI"
QC = "QC"
PO = "PO"
GSL = "GSL"
D = "D"
IC = "IC"
RP = "RP"

order = [RO, CA, RI, PI, QC, PO, GSL, D, IC, RP]
mandatory = [RO, CA, RI, PI, QC, PO, GSL, D, IC]

# Equivalence:  M1 <=> M2 if both mandatory {1}
# If first occurs => same count as second
# For optional RP: (RP,M) holds, (M,RP) does NOT hold
equivalence = {(a,b) for a in mandatory for b in mandatory if a!=b}
equivalence |= {(RP, m) for m in mandatory} # if RP occurs it occurs once like mandatory

# Always Before: (x,y) = if x occurs, y was before
always_before = set()
for i, a in enumerate(order):
    for b in order[:i]:
        always_before.add((a,b))

# Always After: (x,y) = if x occurs, y occurs after
# y must be mandatory, otherwise x mandatory -> y optional would be violated
always_after = set()
for i, a in enumerate(mandatory):
    for b in mandatory[i+1:]:
        always_after.add((a,b))
# RP has no always_after

# Never Together: no exclusive activities in this fulfillment flow
never_together = set()

# Directly Follows: if a occurs, b immediately after
# Cannot use (IC,RP) because RP in {0,1} - if IC occurs RP would be forced
directly_follows = {
    (RO, CA),
    (CA, RI),
    (RI, PI),
    (PI, QC),
    (QC, PO),
    (PO, GSL),
    (GSL, D),
    (D, IC)
}
# In a fully complete log where payment is always recorded, add (IC,RP)

activ_freq = {
    RO: {1},
    CA: {1},
    RI: {1},
    PI: {1},
    QC: {1},
    PO: {1},
    GSL: {1},
    D: {1},
    IC: {1},
    RP: {0,1} # {1} if you consider only closed cases
}

log_skeleton = {
    'equivalence': equivalence,
    'always_before': always_before,
    'always_after': always_after,
    'never_together': never_together,
    'activ_freq': activ_freq,
    'directly_follows': directly_follows
}
```

If you assume only closed orders, set `activ_freq[RP]={1}` and then:

* `equivalence = {(a,b) for a in order for b in order if a!=b}`
* `always_after` includes `(RO,RP)..(IC,RP)`
* `directly_follows` includes `(IC,RP)`
