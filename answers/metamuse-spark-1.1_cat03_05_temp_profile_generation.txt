In this process the normal order is:

`SS < OP < RC < QI < CA < PT < PK < WS < DT < AS`

All eventually-follow pairs therefore occur. The temporal distance is estimated in seconds. Average times are cumulative sums of adjacent steps, standard deviation is propagated as `sqrt(sum(var))` with inflation for long-range dependencies.

Adjacent baseline used:

* SS->OP 3d, OP->RC 14d, RC->QI 1d, QI->CA 2d, CA->PT 2d, PT->PK 2d, PK->WS 0.5d, WS->DT 5d, DT->AS 30d

With a given `ZETA`, e.g. `ZETA=3`, a deviation for pair `(A,B)` is flagged if observed `t_B - t_A < AVG - ZETA*STDEV` or `> AVG + ZETA*STDEV`.

The profile includes both short-range pairs like `('RC','QI')`, `('PK','WS')` and long-range pairs like `('SS','AS')`, `('OP','AS')`, `('SS','DT')` to capture cascading delays across procurement, manufacturing and distribution.
