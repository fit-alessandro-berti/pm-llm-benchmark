**This is a BPMN (Business Process Model and Notation) diagram showing the “Dispatch of goods” process for a Computer Hardware Shop.** It uses three horizontal swimlanes (roles/participants) to organize the activities:

- **Logistics** (top lane)
- **Secretary** (middle lane)
- **Warehouse** (bottom lane)

### Overall flow

1. **Start**  
   The process begins with the start event **Ship goods** (white circle) in the Secretary lane.

2. **Parallel split**  
   Immediately after the start, an AND gateway (diamond with a “+”) splits the flow into two concurrent paths that must both complete before the process can finish:
   - **Secretary path** – administrative / logistics coordination work  
   - **Warehouse path** – physical packaging work

3. **Secretary path – clarifying and arranging shipment**
   - **Clarify shipment method**
   - Exclusive gateway (**Special handling?**)
     - **No** → **Check if insurance is required**  
       (this activity reads the data object *Order details* and the data store *Customer information*)  
       → Exclusive gateway (**If insurance necessary**)  
         - If yes → **Insure parcel** (performed in the Logistics lane)  
         - Always → **Write package label**
     - **Yes** → **Get 3 offers from logistic companies** → **Select logistic company and place order**
   - The insurance and non-special-handling paths merge, then both the special-handling and normal paths join at an exclusive gateway before continuing.

4. **Warehouse path – packaging**
   - **Package goods** (runs in parallel with the Secretary work).  
     A timer intermediate event (clock icon) is attached: if packaging takes longer than **48 hours**, the activity **Notify customer about delay** is triggered, after which the flow rejoins the main packaging path.
   - The packaging path reaches an intermediate event and waits for the Secretary path.

5. **Synchronization and completion**
   - An AND join gateway waits until both the Secretary path and the Warehouse path have arrived.
   - **Fill out Shipment paperwork**
   - **Move package to pickup area**
   - End event **Shipment prepared** (thick-bordered circle).

### Key BPMN symbols used
- **Circles** – start / intermediate / end events  
- **Rounded rectangles** – tasks/activities  
- **Diamonds with +** – parallel (AND) gateways (split or join)  
- **Diamonds with X** – exclusive (XOR) gateways (decisions / merges)  
- **Document icon** – data object (*Order details*)  
- **Cylinder** – data store (*Customer information*)  
- **Timer icon** – boundary intermediate timer event (48-hour delay notification)

In short, the diagram models a concurrent dispatch process in which the Secretary handles shipment method, insurance, labels and carrier selection while the Warehouse packages the goods (with a built-in delay escalation), and both sides must finish before the shipment is marked as prepared.
