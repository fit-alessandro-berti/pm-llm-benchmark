### Final POWL structure (pm4py)

```python
from pm4py.objects.powl.obj import StrictPartialOrder, OperatorPOWL, Transition, SilentTransition
from pm4py.objects.process_tree.obj import Operator

# --- Activities -------------------------------------------------
OR  = Transition("OR")
MS  = Transition("MS")
QS  = Transition("QS")
AS  = Transition("AS")
IQC = Transition("IQC")
TST = Transition("TST")
RT  = Transition("RT")
PK  = Transition("PK")
LB  = Transition("LB")
DP  = Transition("DP")
D   = Transition("D")

# Silent “skip” transitions
tau = SilentTransition()

# --- Inner loop: IQC can be repeated (one or more times) --------
# *(IQC, )  ->  IQC, [IQC, IQC, ...] then exit
iqc_loop = OperatorPOWL(operator=Operator.LOOP, children=[IQC, tau])

# --- Assembly loop ------------------------------------------------
# *(AS, iqc_loop)  ->  AS, [iqc_loopAS, ...] until exit
as_loop = OperatorPOWL(operator=Operator.LOOP, children=[AS, iqc_loop])

# --- Testing loop -------------------------------------------------
# *(TST, RT)  ->  TST, [RTTST, ...] until exit
tst_loop = OperatorPOWL(operator=Operator.LOOP, children=[TST, RT])

# --- Optional labeling --------------------------------------------
# X(LB, )  ->  either LB or skip
label_choice = OperatorPOWL(operator=Operator.XOR, children=[LB, tau])

# --- Top-level partial order (sequential flow) --------------------
root = StrictPartialOrder(
    nodes=[OR, MS, QS, as_loop, tst_loop, PK, label_choice, DP, D]
)

# Execution order: OR  MS  QS  (AS-loop)  (TST-loop)  PK  (LB?)  DP  D
root.order.add_edge(OR, MS)
root.order.add_edge(MS, QS)
root.order.add_edge(QS, as_loop)
root.order.add_edge(as_loop, tst_loop)
root.order.add_edge(tst_loop, PK)
root.order.add_edge(PK, label_choice)
root.order.add_edge(label_choice, DP)
root.order.add_edge(DP, D)
```

### What the model captures

- **`OR  MS  QS`**: mandatory sequential prelude.
- **`as_loop`**: starts with `AS`; if quality checks are needed it executes `iqc_loop` (one or more `IQC`’s, with silent steps in between) and returns to `AS`; when satisfied it exits to testing.
- **`tst_loop`**: starts with `TST`; if the product fails (`RT`) it loops back to `TST`; otherwise proceeds.
- **`PK  label_choice  DP  D`**: packaging, optional `LB` (exclusive choice with silent skip), then dispatch.

This POWL generates all observed traces (0/1/2+ `IQC`s, 0/1+ `RT`s, `LB` present or missing) while keeping the global ordering explicit through `StrictPartialOrder`.
