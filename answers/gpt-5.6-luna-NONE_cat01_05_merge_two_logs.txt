## Matching rationale

- **Order Received / OrderReceived**: Matched by order ID, equivalent naming, and a two-second timestamp difference. The System A timestamp is retained as the primary timestamp.
- **Order Validated / OrderValidation**: Matched by order ID, equivalent naming, and a one-second difference.
- **Payment Processed / PaymentCheck**: Matched by order ID and semantic similarity. The five-second difference exceeds the suggested two-second tolerance, so this is a lower-confidence match. It was merged because both events occur in the expected payment stage and there is no competing payment event. Both timestamps are retained.
- **Quality Check**: Appears only in System B and is retained as a separate event.
- **Item Shipped / Shipping**: Matched by order ID, equivalent meaning, and a two-second difference.
- **Item Delivered**: Appears only in System A and is retained without System B enrichment.

System A timestamps were used as the primary timestamps where available because System A is the designated primary timeline. System B attributes were added to matched events, while unmatched events retain their originating system and available fields.
