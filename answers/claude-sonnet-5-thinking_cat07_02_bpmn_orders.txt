# BPMN Process Diagram Description

This is a **Business Process Model and Notation (BPMN)** diagram depicting an order fulfillment workflow across four organizational departments (shown as horizontal pools/lanes):

## **1. Sales Lane**
- Triggered by a **timer event** (Monday morning)
- Process flow: Check order for completeness  Check if customer is in database
- Contains a **sub-process** "Check customer's order":
  - Decision gateway checks if customer exists in database
  - If not, adds customer to a **database** (shown as a data store)
  - Merges back via exclusive gateway
- Sends **order details** (message) to Production
- Waits for a **"Product sent"** message event
- Finally drafts an invoice and ends

## **2. Production Lane**
- Receives **"Order details arrive"** message (start event)
- Parallel gateway splits into two paths:
  - **Plan production** activity
  - Loop checking **"Material not faulty"** (event-based gateway)
- Both paths converge via parallel gateway into **Manufacture product**
- Ends with **"Product complete"** message event

## **3. Procurement Lane**
- Receives **"Order details arrive"** message
- Contains a **sub-process**: "Material Compensation Subprocess"
  - Order materials  Return material (with compensation marker )
- Followed by **Check materials** task with an attached **timer boundary event** (interrupting)
- Two outcomes:
  - Success path continues to a message send
  - Timeout leads to **order cancellation** (with compensation triggered)

## **4. Warehouse Lane**
- Receives **"Product complete"** message
- Executes **Send product** task
- Emits **"Product sent"** message event

## **Cross-Lane Communication**
Dashed lines represent **message flows** between pools, showing:
- Order details flowing from Sales  Production/Procurement
- Product completion status flowing from Production  Warehouse
- Product sent confirmation flowing from Warehouse  Sales

## **Notable BPMN Elements Used**
- Start/end events (circles)
- Message events (envelope icons)
- Timer events (clock icons)
- Parallel and exclusive gateways (diamonds)
- Event-based gateways
- Sub-processes (nested rectangles)
- Boundary events (timer, compensation)
- Compensation activities (rewind icon)
- Data store (database cylinder)

This diagram effectively models a **complex order-to-delivery process** with material sourcing, potential cancellations, and cross-departmental coordination.
