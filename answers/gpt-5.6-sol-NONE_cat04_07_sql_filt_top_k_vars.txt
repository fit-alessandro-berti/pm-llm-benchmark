```sql
-- Replace ? with the desired value of K.
WITH case_variants AS (
    SELECT
        case_id,
        list(activity ORDER BY "timestamp") AS variant
    FROM event_log
    GROUP BY case_id
),
variant_counts AS (
    SELECT
        variant,
        COUNT(*) AS case_count
    FROM case_variants
    GROUP BY variant
),
top_k_variants AS (
    SELECT variant
    FROM variant_counts
    ORDER BY case_count DESC, variant
    LIMIT ?
),
selected_cases AS (
    SELECT cv.case_id
    FROM case_variants AS cv
    JOIN top_k_variants AS tkv
      ON cv.variant = tkv.variant
)
SELECT e.*
FROM event_log AS e
JOIN selected_cases AS sc
  ON e.case_id = sc.case_id
ORDER BY e.case_id, e."timestamp";
```

`list(activity ORDER BY "timestamp")` constructs the complete ordered activity sequence for each case. Variants are then counted, the K most frequent sequences are selected, and the original events are returned only for cases matching those variants.

If timestamps can tie within a case, add a deterministic event identifier to the ordering, for example:

```sql
list(activity ORDER BY "timestamp", event_id)
```
