**POWL Model for the Global Manufacturing & Distribution Process**

```python
import pm4py
from pm4py.objects.powl.obj import StrictPartialOrder, OperatorPOWL, Transition, SilentTransition
from pm4py.objects.process_tree.obj import Operator

# Atomic activities
OR  = Transition(label="OR")
MS  = Transition(label="MS")
QS  = Transition(label="QS")
AS  = Transition(label="AS")
IQC = Transition(label="IQC")
TST = Transition(label="TST")
RT  = Transition(label="RT")
PK  = Transition(label="PK")
LB  = Transition(label="LB")
DP  = Transition(label="DP")
D   = Transition(label="D")

# Silent transitions (distinct instances)
skip_iqc = SilentTransition()   # used inside IQC+
skip_lb  = SilentTransition()   # used for optional Labeling

# IQC+  (one or more consecutive IQC)
# * (IQC, τ)  ≡  IQC (τ IQC)*
iqc_plus = OperatorPOWL(operator=Operator.LOOP, children=[IQC, skip_iqc])

# Assembly phase
# * (AS, IQC+)  ≡  AS (IQC+ AS)*
# Always starts and ends with AS; ≥1 IQC between successive ASs; pure AS also possible
assembly_loop = OperatorPOWL(operator=Operator.LOOP, children=[AS, iqc_plus])

# Testing / Re-testing phase
# * (TST, RT)  ≡  TST (RT TST)*
# Always ends with TST; RT only appears as redo
test_loop = OperatorPOWL(operator=Operator.LOOP, children=[TST, RT])

# Optional Labeling
# X (LB, τ)
labeling = OperatorPOWL(operator=Operator.XOR, children=[LB, skip_lb])

# Top-level partial order (total order / sequential, as no concurrency is observed)
root = StrictPartialOrder(nodes=[OR, MS, QS, assembly_loop, test_loop, PK, labeling, DP, D])
root.order.add_edge(OR, MS)
root.order.add_edge(MS, QS)
root.order.add_edge(QS, assembly_loop)
root.order.add_edge(assembly_loop, test_loop)
root.order.add_edge(test_loop, PK)
root.order.add_edge(PK, labeling)
root.order.add_edge(labeling, DP)
root.order.add_edge(DP, D)
```

### Why this model is correct
- **Prefix** `OR → MS → QS` is present in every case.
- **Assembly** generates exactly the observed language `AS (IQC+ AS)*`:
  - Case 4: single `AS`
  - Cases 1/2: `AS IQC AS`
  - Case 5: `AS IQC AS IQC AS`
  - Case 3: `AS IQC IQC AS IQC AS`
  - Never starts/ends with IQC, never has consecutive AS without IQC(s).
- **Testing** generates exactly `TST (RT TST)*` (Cases 1/3/5 contain one or more RT-rewinds; Cases 2/4 contain a single TST).
- **Labeling** is optional after Packaging (present in Cases 1/3/4/5, absent in Case 2).
- **Suffix** `PK → (LB?) → DP → D` is universal.
- No concurrency appears in any trace (timestamps induce a total order), therefore a linear chain of edges inside a single `StrictPartialOrder` is the appropriate top-level construct.

This POWL model is minimal, uses only the four allowed constructs, and reproduces every trace in the given event log (and no extraneous behaviour that contradicts the log).
