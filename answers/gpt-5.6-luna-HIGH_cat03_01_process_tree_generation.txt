Let

\[
C =
\to\big(
  'SC',
  X('TM','SPT'),
  'RDT',
  X('FCE','FBA')
\big)
\]

be one abnormal-results treatment cycle. The loop is entered only when the initial diagnostic results are abnormal. If they are normal, the `tau` branch is selected.

The complete process tree is:

```text
->(
    'A',
    'RG',
    'IA',
    'TI',
    'TC',
    X('CE', 'FBP'),

    X(
        tau,
        *(
            ->(
                'SC',
                X('TM', 'SPT'),
                'RDT',
                X('FCE', 'FBA')
            ),
            tau
        )
    ),

    +('AI', 'NC'),
    'FAS',
    'DDI',
    +('BL', 'ICP', 'MRF')
)
```

Here:

- `X('CE','FBP')` selects exactly one initial diagnostic test.
- `X(tau, *(...))` allows the initial test to be normal immediately, or starts the abnormal-results loop.
- The loop cycle is:

  ```text
  ->(
      'SC',
      X('TM','SPT'),
      'RDT',
      X('FCE','FBA')
  )
  ```

- The `tau` as the loop redo step allows this cycle to repeat any number of times.
- `+('AI','NC')` executes imaging and nutritional counseling concurrently.
- `+('BL','ICP','MRF')` executes all three final clearance activities concurrently.

If `RDT` is intended only as the name of the composite follow-up-test stage rather than as a separate activity, the cycle can instead be written as:

```text
->(
    'SC',
    X('TM', 'SPT'),
    X('FCE', 'FBA')
)
```

### PM4Py construction

In PM4Py, a silent leaf is normally represented by `label=None`, which is rendered as `tau`.

```python
from pm4py.objects.process_tree.obj import ProcessTree, Operator


def activity(label):
    return ProcessTree(label=label)


def silent():
    return ProcessTree(label=None)


def node(operator, *children):
    t = ProcessTree(operator=operator)
    for child in children:
        child.parent = t
        t.children.append(child)
    return t


cycle = node(
    Operator.SEQUENCE,
    activity("SC"),
    node(
        Operator.XOR,
        activity("TM"),
        activity("SPT")
    ),
    activity("RDT"),
    node(
        Operator.XOR,
        activity("FCE"),
        activity("FBA")
    )
)

abnormal_loop = node(
    Operator.XOR,
    silent(),
    node(
        Operator.LOOP,
        cycle,
        silent()
    )
)

root = node(
    Operator.SEQUENCE,
    activity("A"),
    activity("RG"),
    activity("IA"),
    activity("TI"),
    activity("TC"),
    node(
        Operator.XOR,
        activity("CE"),
        activity("FBP")
    ),
    abnormal_loop,
    node(
        Operator.PARALLEL,
        activity("AI"),
        activity("NC")
    ),
    activity("FAS"),
    activity("DDI"),
    node(
        Operator.PARALLEL,
        activity("BL"),
        activity("ICP"),
        activity("MRF")
    )
)
```
