```sql
SELECT e.*
FROM event_log e
WHERE e.case_id IN (
    SELECT case_id
    FROM event_log
    GROUP BY case_id
    HAVING COUNT(*) <= 6
);
```

**Explanation:**

- The subquery groups `event_log` by `case_id` and counts the number of events in each case using `COUNT(*)`.
- The `HAVING COUNT(*) <= 6` clause filters this grouped result to only include `case_id`s whose total event count is six or fewer.
- The outer query then selects all columns (`e.*`) from `event_log` for rows whose `case_id` appears in that filtered list, effectively returning every event belonging to a qualifying case.

**Alternative using window functions** (avoids a subquery join, often efficient in DuckDB):

```sql
SELECT case_id, activity, timestamp
FROM (
    SELECT *,
           COUNT(*) OVER (PARTITION BY case_id) AS case_event_count
    FROM event_log
) sub
WHERE case_event_count <= 6;
```

This version computes the per-case event count inline using `COUNT(*) OVER (PARTITION BY case_id)`, then filters directly on that computed column — useful if you want to avoid a separate aggregation subquery and keep everything in a single pass over the data.
