The cases that deviate from the normative process are **Cases 2, 3, and 5**.

| Case | Trace | Conformance | Reason |
|---|---|---|---|
| 1 | Receive  Check  Authorize  Package  Ship  Close | Conformant | Matches the normal sufficient-inventory sequence exactly. |
| 2 | Receive  Check  Package  Authorize  Ship  Close | **Violation** | Items are packaged before payment is authorized. |
| 3 | Receive  Check  Authorize  Cancel  Ship  Close | **Violation** | Shipping occurs after cancellation; additionally, the cancellation path is not followed correctly. |
| 4 | Receive  Check  Cancel  Close | Conformant | Matches the prescribed insufficient-inventory/cancellation sequence. |
| 5 | Receive  Check  Authorize  Ship  Close | **Violation** | The order is shipped without first packaging the items. |

### Case 2 — Packaging before payment authorization
Trace:

> Receive order  Check inventory  Package items  Authorize payment  Ship order  Close order

The normative description requires that:

> “Authorize payment” should only occur after “Check inventory” **and before packaging**.

Here, **Package items** occurs before **Authorize payment**, reversing the required ordering. Although shipping and closing occur afterward, the prerequisite sequence is violated.

### Case 3 — Cancellation followed by shipping
Trace:

> Receive order  Check inventory  Authorize payment  Cancel order  Ship order  Close order

This case has several issues:

1. **Shipping after cancellation** is explicitly prohibited:
   > “Ship order should … never [occur] after a cancellation.”

   Once the order is canceled, fulfillment-related work—especially shipping—should not continue.

2. The cancellation branch should be:

   > Receive  Check  Cancel  Close

   Instead, the case includes **Authorize payment** before cancellation and **Ship order** afterward. If the cancellation reflects insufficient inventory, payment authorization should not occur because the description says the process should proceed directly from inventory checking to cancellation.

3. Even if payment authorization before cancellation were treated as an exceptional or ambiguous situation, the subsequent **Ship order** is still an unequivocal violation. Also, shipping occurs without a preceding **Package items** activity.

### Case 5 — Shipping without packaging
Trace:

> Receive order  Check inventory  Authorize payment  Ship order  Close order

The normal fulfillment path requires:

> Receive  Check  Authorize Payment  Package  Ship  Close

In this case, **Ship order** occurs without any prior **Package items** activity. The description explicitly states that items must be packaged before shipment, so this violates the required packaging-before-shipping rule.

### Conformant cases

- **Case 1** follows the complete normal fulfillment sequence.
- **Case 4** correctly follows the insufficient-inventory cancellation sequence: inventory is checked, the order is canceled, and then it is closed.
