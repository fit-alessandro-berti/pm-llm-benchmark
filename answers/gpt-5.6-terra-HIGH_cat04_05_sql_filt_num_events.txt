```sql
SELECT *
FROM event_log
QUALIFY COUNT(*) OVER (PARTITION BY case_id) <= 6;
```

This calculates the total number of events for each `case_id` using a window function, then retains only rows whose case has six or fewer events.

An equivalent grouped approach is:

```sql
SELECT e.*
FROM event_log AS e
JOIN (
    SELECT case_id
    FROM event_log
    GROUP BY case_id
    HAVING COUNT(*) <= 6
) AS eligible_cases
    ON e.case_id = eligible_cases.case_id;
```
