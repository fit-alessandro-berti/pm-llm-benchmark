In GlobalTeq's process the loop `* (DataCompletenessCheck, RequestMoreInfo)` models the completeness check and the XOR models the bias point.

#### 1. POWL Model WITH Potential Unfairness - XOR branch on affiliation

After `SkillAssessment` the process branches: `CulturalFitCheck` vs. `CommunityAffiliationCheck`. The second branch gives the subjective uplift.

```python
import pm4py
from pm4py.objects.powl.obj import StrictPartialOrder, OperatorPOWL, Transition, SilentTransition
from pm4py.objects.process_tree.obj import Operator

# activities
ReceiveApplication = Transition(label="ReceiveApplication")
DataCompletenessCheck = Transition(label="DataCompletenessCheck")
RequestMoreInfo = Transition(label="RequestMoreInfo")
SkillAssessment = Transition(label="SkillAssessment")
CulturalFitCheck = Transition(label="CulturalFitCheck")
CommunityAffiliationCheck = Transition(label="CommunityAffiliationCheck")
ManagerialReview = Transition(label="ManagerialReview")
FinalDecision = Transition(label="FinalDecision")

# LOOP for data completeness: execute check, if incomplete -> request info -> check again
loop_completeness = OperatorPOWL(operator=Operator.LOOP, children=[DataCompletenessCheck, RequestMoreInfo])

# XOR = bias point: standard evaluation vs. community-affiliation path
xor_cultural_bias = OperatorPOWL(operator=Operator.XOR, children=[CulturalFitCheck, CommunityAffiliationCheck])

# overall partial order
root_unfair = StrictPartialOrder(nodes=[
    ReceiveApplication, 
    loop_completeness, 
    SkillAssessment, 
    xor_cultural_bias, 
    ManagerialReview, 
    FinalDecision
])
root_unfair.order.add_edge(ReceiveApplication, loop_completeness)
root_unfair.order.add_edge(loop_completeness, SkillAssessment)
root_unfair.order.add_edge(SkillAssessment, xor_cultural_bias)
root_unfair.order.add_edge(xor_cultural_bias, ManagerialReview)
root_unfair.order.add_edge(ManagerialReview, FinalDecision)
```

#### 2. POWL Model WITHOUT Unfairness - single standardized cultural fit path

Same sequential structure but the XOR is removed. All applicants go through the same `CulturalFitCheck`.

```python
import pm4py
from pm4py.objects.powl.obj import StrictPartialOrder, OperatorPOWL, Transition, SilentTransition
from pm4py.objects.process_tree.obj import Operator

# activities - same labels, no CommunityAffiliationCheck
ReceiveApplication = Transition(label="ReceiveApplication")
DataCompletenessCheck = Transition(label="DataCompletenessCheck")
RequestMoreInfo = Transition(label="RequestMoreInfo")
SkillAssessment = Transition(label="SkillAssessment")
CulturalFitCheck = Transition(label="CulturalFitCheck")
ManagerialReview = Transition(label="ManagerialReview")
FinalDecision = Transition(label="FinalDecision")

# LOOP for data completeness remains
loop_completeness_fair = OperatorPOWL(operator=Operator.LOOP, children=[DataCompletenessCheck, RequestMoreInfo])

# NO XOR bias - sequential fair process
root_fair = StrictPartialOrder(nodes=[
    ReceiveApplication,
    loop_completeness_fair,
    SkillAssessment,
    CulturalFitCheck,
    ManagerialReview,
    FinalDecision
])
root_fair.order.add_edge(ReceiveApplication, loop_completeness_fair)
root_fair.order.add_edge(loop_completeness_fair, SkillAssessment)
root_fair.order.add_edge(SkillAssessment, CulturalFitCheck)
root_fair.order.add_edge(CulturalFitCheck, ManagerialReview)
root_fair.order.add_edge(ManagerialReview, FinalDecision)
```

`root_unfair` contains `X(CulturalFitCheck, CommunityAffiliationCheck)` which models the potential unfairness, while `root_fair` enforces `PO=ReceiveApplication --> * (DataCompletenessCheck, RequestMoreInfo) --> SkillAssessment --> CulturalFitCheck --> ManagerialReview --> FinalDecision` for all candidates.
