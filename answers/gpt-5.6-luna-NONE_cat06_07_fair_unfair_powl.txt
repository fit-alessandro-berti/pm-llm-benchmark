```python
from pm4py.objects.powl.obj import StrictPartialOrder, OperatorPOWL, Transition, SilentTransition
from pm4py.objects.process_tree.obj import Operator
```

## 1. POWL model with potential unfairness

The application is received, completeness is checked, and missing information may be requested repeatedly. After the skill assessment, an XOR determines whether the applicant receives the standard cultural-fit evaluation or goes through a community-affiliation check that may provide an implicit advantage.

```python
# Activities
receive_application = Transition(label="ReceiveApplication")
data_check = Transition(label="DataCompletenessCheck")
request_more_info = Transition(label="RequestMoreInfo")
skill_assessment = Transition(label="SkillAssessment")

standard_cultural_fit = Transition(label="CulturalFitCheck")
community_affiliation = Transition(label="CommunityAffiliationCheck")

managerial_review = Transition(label="ManagerialReview")
final_decision = Transition(label="FinalDecision")

# Loop:
# DataCompletenessCheck is performed first.
# The loop may exit, or RequestMoreInfo is performed and the
# completeness check is repeated.
completeness_loop = OperatorPOWL(
    operator=Operator.LOOP,
    children=[data_check, request_more_info]
)

# Potentially unfair XOR branch
cultural_fit_choice = OperatorPOWL(
    operator=Operator.XOR,
    children=[
        standard_cultural_fit,
        community_affiliation
    ]
)

# Overall process
unfair_model = StrictPartialOrder(
    nodes=[
        receive_application,
        completeness_loop,
        skill_assessment,
        cultural_fit_choice,
        managerial_review,
        final_decision
    ]
)

unfair_model.order.add_edge(receive_application, completeness_loop)
unfair_model.order.add_edge(completeness_loop, skill_assessment)
unfair_model.order.add_edge(skill_assessment, cultural_fit_choice)
unfair_model.order.add_edge(cultural_fit_choice, managerial_review)
unfair_model.order.add_edge(managerial_review, final_decision)
```

Conceptually, this model is:

```text
ReceiveApplication
    -->
*(DataCompletenessCheck, RequestMoreInfo)
    -->
SkillAssessment
    -->
X(
    CulturalFitCheck,
    CommunityAffiliationCheck
)
    -->
ManagerialReview
    -->
FinalDecision
```

The potential unfairness is represented by the XOR branch containing `CommunityAffiliationCheck`. Applicants taking that path may receive a favorable adjustment based on local or organizational affiliation rather than equivalent evidence of job suitability.

## 2. POWL model without unfairness

In the unbiased version, all applicants follow the same cultural-fit evaluation. The completeness loop and sequential skill assessment remain, but there is no community-affiliation branch.

```python
# Activities
receive_application_fair = Transition(label="ReceiveApplication")
data_check_fair = Transition(label="DataCompletenessCheck")
request_more_info_fair = Transition(label="RequestMoreInfo")
skill_assessment_fair = Transition(label="SkillAssessment")
cultural_fit_fair = Transition(label="CulturalFitCheck")
managerial_review_fair = Transition(label="ManagerialReview")
final_decision_fair = Transition(label="FinalDecision")

# Same completeness loop for every applicant
completeness_loop_fair = OperatorPOWL(
    operator=Operator.LOOP,
    children=[
        data_check_fair,
        request_more_info_fair
    ]
)

# Overall unbiased process
fair_model = StrictPartialOrder(
    nodes=[
        receive_application_fair,
        completeness_loop_fair,
        skill_assessment_fair,
        cultural_fit_fair,
        managerial_review_fair,
        final_decision_fair
    ]
)

fair_model.order.add_edge(receive_application_fair, completeness_loop_fair)
fair_model.order.add_edge(completeness_loop_fair, skill_assessment_fair)
fair_model.order.add_edge(skill_assessment_fair, cultural_fit_fair)
fair_model.order.add_edge(cultural_fit_fair, managerial_review_fair)
fair_model.order.add_edge(managerial_review_fair, final_decision_fair)
```

Conceptually, this model is:

```text
ReceiveApplication
    -->
*(DataCompletenessCheck, RequestMoreInfo)
    -->
SkillAssessment
    -->
CulturalFitCheck
    -->
ManagerialReview
    -->
FinalDecision
```

Here, every applicant completes the same cultural-fit activity, and no affiliation-based XOR path can introduce preferential treatment.
