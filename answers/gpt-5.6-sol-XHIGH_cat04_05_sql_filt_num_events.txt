```sql
WITH eligible_cases AS (
    SELECT case_id
    FROM event_log
    GROUP BY case_id
    HAVING COUNT(*) <= 6
)
SELECT e.*
FROM event_log AS e
JOIN eligible_cases AS c
    ON e.case_id = c.case_id
ORDER BY e.case_id, e.timestamp;
```

The CTE identifies cases with at most six events, and the join returns every event belonging to those eligible cases.
