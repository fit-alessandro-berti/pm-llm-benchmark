### Explanation of Logic

**1. Case Identification - Artifact-Centric:**
The user works on 5 logically independent artifacts. A case was defined as the lifecycle of one artifact. This creates coherent, non-interleaved cases and is standard for desktop activity mining:
*   `CASE-01_DOC_Document1.docx` - Main drafting task, split in two phases by interruptions
*   `CASE-02_EMAIL_Annual_Meeting` - Handling an email in Chrome
*   `CASE-03_PDF_Report_Draft.pdf` - Reviewing a PDF
*   `CASE-04_XLS_Budget_2024.xlsx` - Updating a spreadsheet
*   `CASE-05_DOC_Quarterly_Report.docx` - A separate document, opened briefly at 08:59:50 and properly edited at 09:07:15. Both events belong to the same case.

This was chosen over a single "Work Session" case because it avoids a spaghetti process where Document1 -> Email -> PDF -> Excel appear as one mandatory sequence, which is not true causally.

**2. Activity Naming - Intent Abstraction:**
Raw verbs were abstracted to analyst-friendly terms using `App + Action + Window` context:
*   `FOCUS` -> `Open Document / Open Workbook / Open Inbox / Reopen Document` 
*   `TYPING` in Word -> `Compose Draft` [first creation] vs `Edit Document` [after other work]
*   `TYPING` in Excel -> `Edit Workbook` / `Update Data`
*   `TYPING` in Chrome + `Reply` click -> `Compose Reply`
*   `CLICK Send` -> `Send Email`
*   `SCROLL` -> `Read Email` in Chrome context, `Review Document` in Acrobat context
*   `HIGHLIGHT` -> `Highlight Content`
*   `SAVE / CLOSE` -> `Save Document / Save Workbook / Close Document`
*   `SWITCH` events were removed as they are transport events, except when they represent the only evidence of opening a new artifact, where they were mapped to `Open`.

**3. Narrative:**
The log now tells a clear story: User intended to work on Quarterly_Report, but immediately switched to creating Document1.docx. After a first draft and save, they were interrupted to handle an Annual Meeting email (open-read-reply-send). Then they reviewed a related PDF, updated Q1/Q2 budget figures in Excel, and returned to Document1 to insert a reference to that budget before closing it. Finally, they resumed and completed the initial Quarterly_Report.docx task.
