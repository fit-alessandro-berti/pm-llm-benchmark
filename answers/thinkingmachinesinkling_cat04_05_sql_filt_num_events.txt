Here is a DuckDB SQL query that fulfills the requirement. It explicitly groups by `case_id` to count events, filters out cases with more than six, and then joins back to retrieve the full rows for the remaining cases:

```sql
WITH valid_cases AS (
    SELECT case_id
    FROM event_log
    GROUP BY case_id
    HAVING COUNT(*) <= 6
)
SELECT e.*
FROM event_log e
INNER JOIN valid_cases v 
    ON e.case_id = v.case_id;
```

**How it works:**
1. The CTE `valid_cases` groups the log by `case_id` and applies `HAVING COUNT(*) <= 6` to keep only those cases with six or fewer events.
2. The main query joins this filtered set of `case_id`s back to the original `event_log` table (`e.*`) to return every column for every event belonging to those valid cases.
