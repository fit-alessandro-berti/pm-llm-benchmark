```sql
SELECT *
FROM event_log
QUALIFY COUNT(*) OVER (PARTITION BY case_id) <= 6;
```

`COUNT(*) OVER (PARTITION BY case_id)` counts all events in each case, while `QUALIFY` removes every row belonging to cases whose total event count exceeds six.

Equivalent grouped approach:

```sql
WITH eligible_cases AS (
    SELECT case_id
    FROM event_log
    GROUP BY case_id
    HAVING COUNT(*) <= 6
)
SELECT e.*
FROM event_log AS e
JOIN eligible_cases AS c
  ON e.case_id = c.case_id;
```
